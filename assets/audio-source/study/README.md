# 交互音效原件

仅保存实际使用的八个录音原件，不进入发布目录。来源为 laleksic 的 [Various Sound Effects](https://opengameart.org/content/various-sound-effects)，作者页面明确将录音按 [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/) 发布。页面许可及作者自录说明于 2026-10-16 核对；来源、压缩包摘要和逐文件摘要见 [source.json](source.json)。

使用 `python3 tools/prepare-study-audio.py` 从这些原件重新裁切与导出；参数、交付摘要由脚本写入 `public/audio/study/source.json`。原件是实物录音，没有 AI 或程序合成声音。
