# 阶段 D 日常拟音原料

Kenney [Impact Sounds 1.0](https://kenney.nl/assets/impact-sounds)官方页面与原包[许可文本](Kenney-License.txt)均为CC0。固定包URL、SHA256与选用19个Ogg文件各自摘要见[source.json](source.json)。保留官方Ogg交付层级，不称为无损原录音；未选用文件和原zip不进入游戏发布。

木、硬地、草地分别取同系列4个变化；软面使用3个不同解码结果，排除原包重复的carpet002/004。金属踏面/梯级由同包硬地脚步与轻金属板接触组合，是拟音；草地素材用于当前土质地形，不声称鞋型或地域实录。软面用于床/软座，是织物接触近似；茶几按木质处理。落地叠两次短接触，不代表角色受伤或任务完成。

布帘复用阶段B布料源；转台复用阶段A通用电机公开有损预览，降调并低通，不称为真实灯塔转台录音；UI为项目ISC离线正弦短音。所有借用原料使用相对路径与固定摘要，无重复原件。详见[制作脚本](../../../tools/prepare-daily-audio.py)及[最终交付清单](../../../public/audio/daily/source.json)。

脚本使用macOS AudioToolbox解码/编码，PCM16@48k单声道短声与窗帘循环，转台AAC-LC64k循环。循环交叉淡化、短声去直流与淡入淡出；制作参数与原料层级随发布交付，原料与脚本留在白名单之外。人工材质/接缝/重复感与响度仍待试听。
