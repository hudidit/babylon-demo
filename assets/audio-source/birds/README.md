# 稀疏海鸟短声

[Soojay — Seagulls / gaviotas clean wildtrack.WAV](https://freesound.org/people/Soojay/sounds/462462/)作者页于2026-10-24核实为CC0。使用公开HQ MP3预览（原始24-bit WAV未下载），完整源文件1,770,576 B；地址、SHA256、页面摘要和许可依据见[source.json](source.json)。

[制作脚本](../../../tools/prepare-bird-audio.py)裁取3.45秒与8.70秒附近的0.65秒短段，混为48kHz/单声道PCM16，4500Hz低通、去直流、短淡入淡出，目标峰值0.30。每段为海鸟短叫声片段，非长时间背景录音，也不声称特定地域/季节的鸟种调查。两条交付共124,888 B、PCM249,600 B，见[交付记录](../../../public/audio/birds/source.json)。

不循环、不将鸟叫烘焙到风/浪底声。运行时首次等18～30秒，再间隔32～62秒，只在白天/露天/非强雨且正常探索时发一小段；环境组控制，暂停/进屋重置，没有补播队列。原料与脚本不在发布白名单中，人工下一轮听感仍待确认。
