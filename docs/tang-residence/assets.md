# 素材来源、制作与交付档案

更新时间：2026-10-18。关联：[构件/物品](objects.md)、[历史依据](evidence.md)、[变更记录](change-control.md)。候选来源沿用 `750a5e3` 的调研；本轮没有新增下载、授权或运行资产接入。

## 1. 来源与制作路线

建议采用 **主体建筑原创模块化建模＋重点器物按馆藏重建＋少量 CC0 通用表面素材**。截至初始调研，没有核实可直接下载、形制与断代均适合此宅的整套唐代住宅 GLB；因此不承诺购买一个“唐风资产包”就能满足要求。

| 素材类别 | 取得地点 / 具体入口 | 实施方式 | 历史与许可边界 |
| --- | --- | --- | --- |
| 柱、梁、檩椽、门、窗、瓦、台基 | H01—H03、待调阅南禅寺资料 | 原创参数化建筑模块；复杂接合可在 Blender 制作，再输出受控 GLB | 不下载宫殿/寺庙整模充当住宅；建模前为可见细节补证 |
| 榻、几案、屏具、箱、床 | H03、H04 的具体图像；补充唐墓图版后固定原型 | 自建约 6—8 种可复用家具原型，改变摆放而非拼凑朝代 | 研究图片仅作参考，不自动获得贴图或扫描模型的再发布许可 |
| 碗、砚、镜、卷 | H05—H08 的馆藏页面、尺寸与正侧面资料 | 回转体建碗与陶罐；雕纹、器足依原型重建；卷轴和纸面自制 | 研究尺寸与取得图片使用权分别记录；H05/H06 仍需核对目标时段和明器属性 |
| 木材微表面 | Poly Haven [Rough Wood](https://polyhaven.com/a/rough_wood)，Rob Tuytel；本项目已有 [Wood Table 001](https://polyhaven.com/a/wood_table_001)，Dimitrios Savva / Rico Cilliers | 前者仅作未髹饰木材的颗粒候选，去掉过度朽裂；后者只取适量木纹并重新设计漆层 | 两者是现代扫描表面，非唐木材样本；漆木不能让深木纹穿透整层漆 |
| 浅色抹面 | Poly Haven [White Rough Plaster](https://polyhaven.com/a/white_rough_plaster)，Rob Tuytel | 仅选择适用微表面，控制剥落；主体也可原创程序化生成 | 扫描材料配方不作为唐代证据，不整面复制废墟般破损 |
| 院地 | Poly Haven [Dry Ground Rocks](https://polyhaven.com/a/dry_ground_rocks)，Rob Tuytel | 减弱大石与深裂缝，用作整实土面的细节候选；砖铺另原创 | 本场景是有人维护的宅院；土色和尺度由参考与画面确定 |
| 织物、席与瓦面 | 原创编织/瓦面；[ambientCG](https://ambientcg.com/) 仅作备用筛选库 | 席条、边缝与瓦列模块自行建立，通用纤维只提供微表面 | 初始调研未选定 ambientCG 具体资产，不能把检索入口写成已取得素材 |
| 屏画、织物纹样、文字 | H03 的联屏组织、H08 的书写形态；画面和书信原创 | 先绘普通花木或素屏方案，纹样、行款再经历史复核 | 不把宗教壁画整张贴在宅内；不混入宋体印刷字、后世诗文、清宫收藏印 |
| 铜镜背图像 | H07 对应 Met 图片，页面标记 Public Domain | 可作为重绘、雕纹的开放图像来源；项目保留藏品号与下载记录 | 初始调研核实的是图片开放标记，没有取得可直接用的三维扫描模型 |
| 环境与音效 | 现有已记录的 CC0 环境/录音，或后续自录木门、脚步与纸声 | 按本宅门轴、砖土和纸张重新试听选型；日光、天空优先复用工程能力 | 不直接播放含现代交通、空调、电器的录音；海岸环境只复用技术，画面与声景另选 |

Poly Haven 的[资产许可](https://polyhaven.com/license)与 ambientCG 的[许可说明](https://docs.ambientcg.com/license/)均明确提供 CC0 资产；Poly Haven 的网站文字、标志与示例渲染不因此一并成为 CC0。馆藏网页可看、古物年代久远和扫描文件可下载，都不能自动推导为图片或模型可任意再分发。未查到开放标记或明确授权的馆图保持“研究参考”，实际贴图优先原创，授权未确认的扫描资产不进入运行白名单。

正仓院的[赤漆欟木胡床](https://shosoin.kunaicho.go.jp/treasures/?id=0000014625&index=1108)可作为奈良时代器物的后续比较入口，但初始调研只核实检索条目，动态详情未完整载入；不据此确定家具尺寸，不把日本制作、异地保存的器物一概称为中国唐代进口原件，也不照搬整套日式室内。

## 3. 实际资产必填项

每个实际文件记录 `AS ID / 所属制作包 / 对应 EL、OT、PL / 类别 / 作者 / sourceUrl / 馆藏号或来源版本 / 原型年代地域 / 原件尺寸与单位 / 明确适用许可与凭据 / 原件路径与 SHA256 / 处理工具版本和参数 / 输出路径、字节、SHA256 / 色彩空间与通道语义 / GLB 扩展及外部依赖 / 使用场景与实例 / 发布白名单位置 / 实现和复核状态 / 验收证据 / 最近 CR`。

程序几何记录生成模块/配置版本、输入参数与实例范围；不因没有 GLB 而省略建模来源或运行成本。内容共享时能反查所有使用者，替换贴图须检查每个使用场景的比例、漆层、色彩和磨损。

未建立的字段写明待办；无独立文件的程序几何写“不适用，并指向生成代码”，不能用空摘要代表已校验。原件、高分辨率参考、候选与实际交付分开，避免重复有损压缩。

## 4. 接入与替换检查

1. 对照 SET 和 H 核实本宅适用性；确认取得的是研究参考、可改用图像还是可交付模型，分别记录权限范围。
2. 固定原件与摘要，从原件加工；核对米制、法线方向、sRGB/线性数据、ARM 通道、UV、材质与外部依赖。
3. 将输出绑定 EL/OT/PL 及实际代码；登记全部被复用位置、实例数量或生成规则，检查画质、接触、碰撞与交互。
4. 同步运行白名单、许可说明、全部动态分包和预算；实际首屏包含必需异步 JS。预算与验收沿用[资源原则](../resource-optimization-principles.md)和[技术方案](../technical-plans/2026-10-18-tang-residence-scene.md)。
5. 被替换资产保留历史记录并指向后继；确认没有其他使用者后才从当前发布清单删除。不得把移出当前清单等同于删除历史依据或旧版本。

现有古董柜、书架、装饰画的未核实许可不能继承为唐宅授权；现代家具与设施也不能仅因已有文件就迁入。历史依据、许可核实、文件校验、画面和交互验收分别报告。
