## 2. 通行与功能关系

- 南侧巷道 → SP-012 → SP-011 → SP-010 → SP-003；由廊进入两侧房间。SP-003—SP-005 的完整隔断、门扇与内部通行仍待定，不默认穿过寝室去书斋。
- SP-013、SP-014、SP-015 分别向院侧进入；厕屋无穿过厨房的必经路线。取水先表现为厨房水缸，不默认每宅有井。
- 日间采光先依据南向开口、院落与檐深设计；窗位、分格和开合方式在补证后登记。排水须有坡向和出水去向，不能与饮用水储存相冲突。
- 房间用途调整时复查使用者、物品、火源/烟熏、采光、遮挡/私密、路径、碰撞、地图、音效和 UI 名称，见[影响矩阵](change-control.md)。
