# 构件、物品与布置档案

更新时间：2026-10-18。关联：[设定](scene-profile.md)、[空间](spaces.md)、[史料](evidence.md)、[素材](assets.md)、[变更](change-control.md)。当前条目均为计划，尚无唐宅代码节点或已接入模型。

## 1. 登记规则

每个构件/物品都继承 SET-001（年代）、SET-002（地域）和 SET-012（真实性）约束；下表再列特别相关的设定。来源栏“待补证”表示暂无可直接定稿的原型，不能以物品常见或素材可下载代替历史依据。H 的采用范围以史料档案为准，素材候选不表示已经采用。

EL 是建筑构件或可定位构件组；OT 是物品类型；PL 是某空间中的布置记录。类型尺寸、材质和原型在 OT 维护，数量、位置、用途和实例差异在 PL 维护。所有计划数量都不能当成当前运行场景数量，未定的数量不得记作 0。

## 5. 扩充和实施时的记录

每个实际布置补充：`稳定 ID / 空间 / 类型及原型版本 / 数量或实例组生成规则 / 使用者与用途 / 位置朝向 / 实际尺度 / 表面与磨损 / 文字内容 / 交互与音效 / 碰撞和净空 / 依赖 SET / H 及采用理由 / AS 交付文件 / 代码或配置映射 / 实现状态 / 历史复核状态 / 验收证据 / 最近 CR`。

组合条目在成员具有不同来源、许可、尺寸、交互或验收状态时必须拆分，保留组到成员的关系。相同模型复用时保留每个布置的差异；不得因某一个碗通过验收就将全部厨房器皿标为已验证。

首版不放三彩马俑、镇墓兽等作家居装饰，不混入成熟元明青花、清代粉彩、现代电器、后世线装书海或日式整室布置。记录“不采用”时写本宅理由，不扩大成“整个唐代不存在”。

饮茶组合不加入盖碗、公道杯、紫砂壶或现代整套功夫茶盘；H10 的晚唐高等级银茶托目前仅为排除对照。院内不默认增加成熟江南园林的太湖石、曲桥鱼池、月洞门，也不放鸟居、枯山水和日式石灯笼。不直接用《韩熙载夜宴图》、宋画、明清图录或仿唐影视布景证明本宅细节；跨时代参考必须明确类比范围。
