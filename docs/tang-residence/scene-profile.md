# 场景与住户设定

更新时间：2026-10-18。当前工作版本：`0.1`。初始设计依据：`750a5e3`；维护规则：[档案入口](README.md)；决策与变化见[变更记录](change-control.md)。

## 1. 当前设定

下列为初始方案的创作选择，并非“唐代所有家庭都如此”的历史结论。除用户明确要求的历史真实性与文档维护外，具体年份范围、身份、地块及季节均为可调整的工作设定。`SET` 编号跨版本保留。

| ID | 主题 | 当前值与状态 | 影响范围 |
| --- | --- | --- | --- |
| SET-001 | 年代 | 公元 780—820 年前后；工作设定。精确年份待定，暂不出现需要具体年号/日期的铭文 | 建筑细部、家具、器型、茶事、书写内容、服饰和后续人物 |
| SET-002 | 地域与位置 | 长安地区、里坊环境中的住宅；工作设定。具体坊名、宅址及唐尺换算待定 | 地块与巷道、材料供应、植物、气候表现、背景声与地图文字 |
| SET-003 | 宅主背景 | 虚构的文士，有读书、接客、饮茶活动；工作设定。姓名、年龄、性别、官职/品阶、仕途经历均未定 | 书斋、藏书/文书、接客方式、艺术物品、装饰等级与身份说明 |
| SET-004 | 家资与物资获得 | 有一定家资、有人维护的宅院；工作设定。收入来源、产业、消费水平的具体量级与贸易联系待定 | 面积、维护磨损、漆木/织物、器物数量、奢侈品与外来器物是否合理 |
| SET-005 | 住宅用途 | 私人家庭居住，兼读书与有限接客；工作设定。无商铺、寺院、官署或宫廷功能 | 房间功能、出入口、宾客路线、招牌/陈设、储藏规模、工具种类 |
| SET-006 | 家庭与人员 | 人数、亲属关系、年龄结构、访客频率、是否有雇工/仆役全部待定 | 床位、席位、食具与衣物数量、私密分区、家务与储藏、人物对白 |
| SET-007 | 信仰与个人经历 | 待定；不因参考佛教壁画而默认全家信佛，不默认有佛堂、祭祀空间或特定收藏癖好 | 宗教陈设、书卷内容、香具、人物背景、题字与空间用途 |
| SET-008 | 季节与时段 | 初秋、白昼主展示；工作设定。局部油灯夜景为后续辅展示。具体天气/日期与全院昼夜系统未定 | 植被、落叶、席褥/帘帐、衣物、光照、灯具使用、声景与食物 |
| SET-009 | 生活活动 | 读书、起居、寝卧、接客、煎茶、烹煮与储藏；工作设定。完整家务、烹饪及人物模拟不属首版 | 家具尺度、器具组合、使用磨损、交互步骤、照明和空间通行 |
| SET-010 | 建筑与空间 | 单层、单主院与南侧附属区；工作设定。详细尺寸/用途只维护于[空间档案](spaces.md) | 屋架、门窗、家具布置、地图、碰撞、采光、排水与资源量 |
| SET-011 | 视觉与维护状态 | 生活中、有人维护；灰瓦、暖灰白墙、木褐与有限暗朱/黑漆；工作设定 | 表面粗糙度、磨损/烟熏分布、漆层、装饰密度与环境光；不做千年废墟表面 |
| SET-012 | 真实性与体验边界 | 用户要求建筑/装修/物品符合历史特点。采用有依据的假想复原；不得冒称某真实唐宅原样复原。屏幕 UI 不属于古代实体物件 | 所有原型选择、资料说明、比例、交互、地图标签、宣传与验收 |

## 2. 与物品呈现直接相关的约束

- 未明确的官阶不能用来证明某种门制、斗栱或宫廷装饰可用；确需体现身份时先补充 SET-003 的具体设定及依据。
- “有家资”不足以支持批量摆放金银、玻璃与异域奢侈品；每件特殊物品需要取得背景、数量与史料理由。
- 家庭人数未定，不从暂定床、席、碗的数量反推家庭成员。增加儿童用品、仆役空间或多套卧具须先补 SET-006。
- 宗教图像只提供被说明的特征；不从史料来源推导本宅信仰和人物经历。卷轴是内容载体，宗教经卷、家书和政务文书分别审核。
- 现代扫描贴图只帮助表现微表面，不证明唐代材质配方；古物出土后的腐蚀、褪色、修补与后配装裱，不直接作为当年日用外观。
- 历史原型日期、场景时间与素材制作/查询日期分开记录。较早器物延续使用是需说明的选择；较晚器物不得因统称“唐代”而提前出现。

## 3. 调整本档案时

同步建立[变更记录](change-control.md)，明确旧值、新值、指令或证据出处，以及受影响的空间、构件、物品、素材和表现。修改设定不等于所有下游自动通过，必须逐项复查并留下未完成事项。

不为填满表格编造主人姓名、官阶、收入或家庭人口；需要具体信息的实现先暴露依赖，再依据已有授权确定工作设定。只有确实需要用户偏好或授权时才提问，不因本档案自行增加逐项审批流程。
