## 1. 背景与现状

用户要求把次卧的窗户改到面朝大海的方向，与阳台朝向一致。

当前实现核对：

- [HouseLayout](../../src/examples/HouseLayout.ts)中次卧为5.4×3.6m，平面南侧为大海；阳台位于同一南侧，向海边缘为`y=12.3m`。[CoastalCliff](../../src/examples/CoastalCliff.ts)明确“南侧开向大海”，海面、崖壁和天空共用固定世界坐标。
- 次卧唯一的[窗户配置](../../src/examples/HouseStructure.ts)在**西墙**`x=0, y=8m`，朝西看到的是内陆草坡和植被，不是海。窗户下方布置了阅读凳；次卧日光也从西侧进入。
- [HouseArchitecture](../../src/examples/HouseArchitecture.ts)按开洞数据自动切墙，但窗框/窗帘/窗台的朝向原先按“轴线+坐标”硬编码，所有东西向墙都套用北墙的朝向。直接改数据会让南墙窗户的窗台、窗帘装到室外一侧。
- 现有[海边悬崖阶段C验收](assets/coastal-cliff-c-2026-10-17/README.md)记录115项测试和495个发布文件，预算为运行素材16MiB、两目标GLB 4.25MiB、首屏JS 3MiB、完整发布41MiB；本改造不引入新下载素材。

## 2. 目标与范围

- 将次卧窗户移到南外墙，窗洞净宽2.0m、窗台0.9m、高1.5m，沿墙中心`x=3.9m`（占`x=2.9～4.9m`）；原西墙恢复完整实体墙。
- 窗户外侧朝南，与阳台一致；从室内透过玻璃能看到同一世界的海面、崖缘和天空。
- 窗框、窗台、玻璃、窗帘和横竖分隔随墙面朝内安装；原有透明玻璃、窗洞安全碰撞和可开闭交互不变。
- 阅读凳移到南窗下，保持1.3×0.45m软垫、木架、托盘与书籍；床、床头柜、衣柜、门和房间尺寸不变。
- 次卧日光改从南窗进入；保持原光强、范围、阴影尺寸和房间归属，不改变全屋其他房间的光照。
- 调整次卧环绕预设，使南窗、阅读凳和室内关系在该视图中可见；保留横竖屏退远与操作。
- 保持pure导入、共享素材、独立发布和四项预算；不新增贴图、模型、依赖或停用的性能实验。

## 3. 方案及取舍

### 3.1 以房间边界推导窗户朝向

新增纯函数`houseWindowSide(window)`：根据窗户坐标与所属房间边界返回`north / south / east / west`。窗户朝向由数据决定，但窗台/窗帘的朝内方向不再硬编码。

- 北墙：室内方向为世界`+Z`，窗模型旋转`π`；
- 南墙：室内方向为世界`-Z`，旋转`0`；
- 西墙：室内方向为世界`+X`，旋转`-π/2`；
- 东墙：室内方向为世界`-X`，旋转`+π/2`。

`HouseArchitecture`用同一函数选择旋转角，测试用同一函数推导向内法线，避免实现和测试各写一套镜像逻辑。窗户仍只记录房间、轴、位置、尺寸、窗台和高度；不新增需要人工同步的朝向字段。

### 3.2 数据驱动的墙体开口

`houseWallSpans()`已按窗洞起点和终点切分墙体。把窗户从西墙移到南墙后，南墙自动生成“两端实体墙+窗下矮墙+窗上过梁”四段，原西墙合并为一段实体墙。两处均使用现有共享墙面材质、碰撞和剖面显隐，不新增网格类型或材质；开洞位置避开床尾、墙角及东侧门洞。

窗户宽度沿用2.0m，与旧窗一致；沿墙中心放在`x=3.9`，让阅读凳和床尾之间保留约0.76m净走道。窗户不跨越床的上方，避免玻璃/窗帘与床头碰撞；不在内墙伪造“面海”窗，因为内墙看不到室外。

### 3.3 家具、灯光与预设同步

- 阅读凳绕竖轴旋转90°，长边沿南墙，根部放在次卧局部`(3.9, 3.3)`；凳背离南墙内表面约25mm，凳前沿距床尾约0.76m。仍保持实体碰撞，书籍托盘随凳一起转向。
- 次卧日光移到窗内约0.16m、窗中心高度1.8m处，方向指向室内北侧并向下；保留原`SpotLight`参数、1024²阴影和房间隔离。
- 次卧环绕预设改为从北偏西看向南窗，FOV 0.8，让南窗、阅读凳和窗内海景成为该视图的主体；剖面仍隐藏近侧墙体。竖屏拉远系数封顶1.9，避免近景预设被放大成全屋鸟瞰；以实际截图迭代位置/目标，不改其他房间或全屋相机逻辑。
- 不旋转整个房屋或次卧（会改变床、门、地图和碰撞），不复制一套南向窗贴图，不把玻璃改成不透明风景片。

### 3.4 走道与安全边界

现有次卧通路测试从床尾到西侧夜间柜。阅读凳移到南墙后，床尾与凳前沿之间仍可通行；测试改到该实际0.76m通道，并继续验证入口门全角度扫掠、床/衣柜/阅读凳实体阻挡。窗玻璃仍作为不可穿越的安全边界，不开放室外行走。

## 5. 验收方法

- 数据/几何：次卧窗为南墙`axis=x`、`y=10.8`，沿墙范围在房间内且不与门/墙角冲突；西墙不再有窗洞；窗框/玻璃/窗帘内法线指向房间，玻璃仍透明且阻挡穿越；墙体无重复或漏空。
- 家具/通行：阅读凳完整位于房间和窗下，落地、不与窗台/墙穿插；床尾—阅读凳通道可通过实际0.26m半径碰撞；入口门全角度不碰家具；衣柜/床仍是实体阻挡。
- 光照/画面：日光从南窗方向进入且不被窗框/窗帘遮挡；次卧预设能看到南窗；第一人称从室内看海时海平线、崖缘、天空层次正常，窗框和窗帘无反向/悬浮、无z-fighting；原西墙为完整墙面。
- 回归：门、灯、地图、物品、设置、Inspector、主卫镜面和海岸动画不受影响；浏览器无新增运行/着色器错误、404或告警。桌面与390×844/844×390竖横屏的次卧预设、窗内看海、实体西墙、南立面及原交互均需保存画面。
- 工程/预算：`npm test`、`npm run typecheck`、开发构建、生产构建与`verify:release`通过；运行素材、GLB、首屏JS和完整发布继续满足16/4.25/3/41MiB预算；不将静态截图或固定delta当作FPS/加载速度收益。
