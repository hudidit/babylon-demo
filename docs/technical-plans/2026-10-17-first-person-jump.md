## 1. 背景与目标

用户要求第一人称整体提速50%，并增加空格跳跃：可以跳到沙发、椅子、茶几和床上，但不能跳到书桌/桌面、柜子上，也不能越过阳台栏杆到屋外。

现状：

- [Room](../../src/examples/Room.ts)的`MOVEMENT_SPEED.base`为`0.55`，设置面板的倍率不变；第一人称高度由[HouseWalking](../../src/examples/HouseWalking.ts)每帧强制回`HOUSE_EYE_Y`，没有重力和垂直输入。
- 水平碰撞由Babylon相机碰撞和L形边界保护完成；家具均参与碰撞。如果直接开启`applyGravity`，相机会落在所有可碰撞家具顶部，无法区分允许和禁止的表面。
- 当前镜头高度1.6m、半径0.26m、净高2.8m；家具顶面从0.44m（沙发座）到0.73m（床的折叠毯顶面）不等。

## 2. 方案及取舍

### 2.1 速度

把共享基础速度从`0.55`提升到`0.825`（1.5倍），设置面板的0.25～3倍率、`WASD`/方向键和原有惯性不变；默认倍率仍显示1.00×，但实际速度为原来的1.5倍。没有任何按房间或视角的例外。

### 2.2 垂直控制器

新增[HouseJump](../../src/examples/HouseJump.ts)，以米为单位保存`feet`、`velocity`、`grounded`和跳跃请求：

- 重力9.81m/s²，地板起跳最大高度0.72m；低于桌面（书房桌约0.78m）和阳台栏杆（1.1m），从地面起跳不可能落到桌面或翻出栏杆。
- 在室内净高2.8m下按当前站立高度限制跳跃高度（站立在0.73m床上时剩余头顶空间约0.39m），避免镜头穿过天花。
- 只在下降且越过台面时落地；平台边缘增加0.3m“攀上”辅助。`originTop`记录起跳/离开平台的顶面，攀上只允许更高平台，避免走下平台时被吸回。平台边缘按玩家半径保留支撑，让身体完全离开台面后再下落。
- 水平碰撞仍交给Babylon；跳跃只改变相机Y，相机碰撞体底部随脚高度上升，脚高于家具顶后可以进入其上方。进入房间视图/第一人称时重置为地面状态。
- 桌面、窗边控制台、古董柜和床头柜登记为`HOUSE_JUMP_BLOCKERS`：即使从椅子/床再次起跳，也会在水平方向被退回，不能落在其上。阳台栏杆、外墙和室外边界继续由原碰撞及`constrainHouseXZ`保护。

### 2.3 可着陆白名单

`HOUSE_JUMP_PLATFORMS`仅登记以下表面，尺寸和顶高按实际构件计算：

| 平台 | 位置/依据 | 顶高 |
| --- | --- | --- |
| 客厅主沙发 | `HOUSE_CONTENT.sofa`，seat()座垫 | 0.441m |
| 阅读沙发 | `reading-sofa` 导入模型 | 0.46m |
| 阅读扶手椅 | `reading-armchair` 导入模型 | 0.48m |
| 书房椅 | `HOUSE_CONTENT.chair` 座垫 | 0.561m |
| 茶几 | `living-coffee-table` 台面 | 0.468m |
| 主卧/次卧床 | 折叠毯顶面（避开毯侧碰撞） | 0.73m |
| 次卧窗下阅读凳 | 软垫顶面 | 0.5m |

书桌、窗边桌、床头柜、衣柜、书柜、厨房/卫浴台面、壁炉、陈列柜和栏杆均不在白名单；不通过“所有碰撞体都能站”来绕过限制。

### 2.4 输入与提示

- `Space`在`keydown`（非repeat）时请求跳跃；仅在非模态、控件启用时处理，输入框/设置面板中不拦截。空中不再响应第二次跳跃。
- 第一人称提示增加“空格跳跃”；鼠标未锁定时也提示空格可用。
- 进入第一人称重置为地面，退出时不再更新垂直状态；地图/物品查看期间冻结跳跃。

6. 更新索引、变更日志、验收记录并提交推送。

## 4. 验收方法

- 基础速度1.5倍；设置面板倍率、移动惯性、转向、碰撞和原路线不变。
- 空格从地面起跳后相机上升再回到眼高；空中不能二段跳；在沙发上可再次起跳且不穿天花。
- 分别落在主沙发、阅读沙发/扶手椅、书房椅、茶几、两张床和阅读凳上，相机高度等于对应顶面+1.6m；离开平台会落回地面。
- 桌面、控制台、古董柜、床头柜不可站立；阳台栏杆和室外边界不可越过。
- 门/灯/地图/物品/设置/Inspector、第一人称进出、相机层和原碰撞回归通过；无运行/着色器错误、404或新增告警。
- `npm test`、`npm run typecheck`、开发/生产构建及`verify:release`通过；运行素材、GLB、首屏JS和完整发布预算不变；不把截图/固定delta当作FPS或加载耗时收益。
