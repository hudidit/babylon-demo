# 灯站设备UI：现场工作台

状态：已完成（工程/Chrome设备与布局验收）。创建及更新：2026-10-22。输入基线：`67c33ff`。前置：[故事值守簿UI](2026-10-22-game-ui-field-journal.md)、[六组现场玩法](2026-10-20-lighthouse-focused-experience.md)及[本地值守保存](2026-10-21-lighthouse-two-levels-and-save.md)。遵循[资源与首屏优化原则](../resource-optimization-principles.md)。

## 背景与目标

用户认可值守簿改造后，要求优化设备交互UI。原设备面板为660px纵向仪表、说明、操作及存档；桌面首层面板底部需滚动，文字层级较碎，保护面通用状态球缺少设备含义，与新值守簿的视觉存在差异。目标是统一灯站视觉，按当前设备突出真实读数、下一步及工作记录，保持六组现有玩法和当地权限。

## 范围及取舍

- 覆盖运行面板、灯座试灯、保护面、太阳能面板/控制器、电池、备用灯及只读设备；纸质记录、存档与准星工作反馈随同优化。
- 调整原生HTML/CSS/SVG与`LighthousePanel`展示状态；不修改剧情/设备模型、实际工作时长、当地距离/视线权限、天气安全门控、独立存档格式与六组命令范围。
- 新导航为设备现场、巡视记录、保存进度。记录夹默认记录；保存页仅在首层运行面板/记录夹提供，保持原场景权限。故事联络继续跳转原值守簿，不在设备内复刻任务或消息。
- 读表/试灯/清洁/供电继续调用原命令；页签、焦点和滚动是展示状态，不能产生检查证据。主行动随当前可用动作变化，次要对照/细查保留，不新增维修/柴油/主备手动入口。

布局草案：

```text
设备名 / 现场位置                              返回场景
当前日时、天气与会话模式
设备现场       巡视记录       保存进度       [故事值守簿]
┌─仪表/设备状态─────────┬─当前可做的事──────────┐
│ 真实读数与刻度/状态图  │ 操作说明、表面发现与按钮 │
└─────────────────────┴──────────────────────┘
查看时暂停                                  键盘说明
```

文字左对齐；读数居中以对应实物表盘。仪表是唯一视觉重点，不增加虚构设备编号/评分、装饰性仪表或无关概念图。无仪表的保护面/传感器/机房使用对应原创线描和真实状态，替换通用状态球。页头、导航、返回及页脚固定，内页独立滚动。手机堆叠为仪表→操作；短横屏维持双列但允许内页滚动，保留按钮44px与安全区。

方案复核：只把旧金属外壳换成新配色仍会留下长表单和被截断的存档，因此先把读数/记录/存档分开；也不把设备界面做成另一份信纸，保留真实仪表与独立操作页，让故事阅读和现场操作具有同一视觉来源及各自用途。通用状态球改成设备线描，不画假故障/假检修过程。

导航采用原生dialog加页签状态，Tab环绕、方向键/Home/End、Esc从记录/存档退回现场（记录夹返回记录），再Esc关闭；返回场景按钮始终可直接返回。翻页后焦点保留，隐藏/失效操作不留焦点。只在原快照变化时更新展示，不新建每帧轮询或CSS计时。准星圆环保留原实际活跃计时/中断条件。

## 实际结果

已重做[设备工作台](../../public/index.html)及[展示控制器](../../src/examples/LighthousePanel.ts)。桌面为海墨仪表区与雾纸操作页双列，手机纵向堆叠；独立记录和存档页替代旧纵向长表单。12处入口沿用当地设备权限；试灯、表面、太阳能、电池和只读设备显示各自真实状态，主行动随可用工作变化。保护面/传感器/机房改用对应原创线描，准星环只调整字号与配色，原实际计时保持。

页头/返回/页签/页脚固定，内页独立滚动；记录保持当前设备筛选、五条分页及最近七日。保存页只在运行面板/记录夹可见，故事/正常/演练继续调用原保存适配。页签、翻页和滚动不修改设备事实；加载错误停留保存页，隐藏/禁用动作和清除错误后接续可用焦点。

### 截图及交互复核

- 仪表名称原先在SVG内部，手机会缩成小字：移到HTML文字，保留15px名称和清晰数值；刻度与指针仍按真实量程/value计算。
- 手机的长记录结果原先挤在三列表格中：改为每条上排时间/项目、下排完整结果的布局；桌面保留对齐表格，原文和分页保持，表头保留可访问语义。
- Esc在记录/存档先回现场（记录夹回记录），再返回场景；页脚说明当前去向，只有直接关闭时在返回按钮显示Esc提示，避免按钮暗示与实际返回层级不一致。
- 保护面检查后原按钮隐藏时，焦点接到清洁主操作；继续遇到坏档后接到明确清除，清除后接到保存；记录分页到边界时保持可用焦点。
- 本轮设备流程先读表再清洁，按原设备修订使旧读数仅作历史；实际重新读表后才恢复完整清单，页面未补造证据。观察进度截图保持原视线，不在指针锁定时移动截图鼠标。
