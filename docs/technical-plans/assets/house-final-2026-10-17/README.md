# 阶段G：阳台与整屋收尾验收

2026-10-17，基线为阶段F `afd1fc7`。对应[新户型实施方案](../../2026-10-16-house-layout-implementation.md)，F验收见[厨房与公卫](../house-service-2026-10-17/README.md)。本阶段完成后A～G全部完成。

## 实际交付

- [阳台布置](../../../../src/examples/HouseBalcony.ts)：西端1.2m软垫长凳、直径0.36m边桌/茶杯及两端盆栽。复用原栏杆、安全碰撞和木纹/织物/植物组件，中央留连续通路；新增512²缓存日光阴影。
- [推拉门组件](../../../../src/examples/RoomFurnishings.ts)在既定2.4m洞口内生成双轨玻璃门，一扇固定、一扇向右叠合，左侧净开口约1.14m。两面把手、低轨道、透明玻璃均有真实几何，关闭阻挡、打开可双向通过，固定扇始终阻挡。两扇共享一个动作，叠合时也能从阳台侧关闭；玻璃复用窗材质，无HDR室内假倒影。
- [平移交互](../../../../src/examples/RoomInteractions.ts)独立于旋转门，扫掠整个帧步，遇人暂停/停声、点击反向可离开，中途反向保持位置连续。运动矩阵、碰撞、双面拾取、空间声源及客厅/阳台两房阴影随实际位置同步；原门/开关录音共享，模态/退出/销毁会停声和注销动作。
- 全屋八房ready，新增阳台预设并同步地图/门符号。全景及九个全屋/房间预设支持横竖屏取景，环绕半径上限随比例调整，不把竖屏退远压回旧上限；方向变化保留用户相对缩放。室外仅在环绕剖面模式按房屋近侧边界裁切，避免退远后树木挡住房屋，远侧窗景保留；第一人称使用完整森林。裁切使用室外材质的第二平面，保留镜面所需的第一平面，不设置全局Scene裁切；室外几何也明确排除室内交互射线。
