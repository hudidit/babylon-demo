## 实现和实际操作

- [巡检模型](../../../../src/examples/LighthouseInspection.ts)独立维护三项清单、带时刻的观察、表面修订、可取消清洁事务与最近7个值守日的摘要/事件。运行模型继续是日程、转台和导航的唯一事实来源；检查不会起灯、停灯、增加供电/电机“耐久度”或发放奖励。
- 首层面板点击“确认本次读数”形成`check-control`观察。重复读取更新本次观察时刻，相同结果不重复增加事件；记录注明当时的自动/试灯方式与实际灯态，不从历史读数推断当前全面正常。
- 顶层白天先从原局部入口试灯，返回场景近距离看向灯头。`check-optic`要求连续10个共享时钟接受的活跃秒、实际相位累计一圈并采到方向出光；约25°视线锥、1.5米距离、对应楼层/第一人称落地和最近命中均检查。转头、遮挡、离开或停转重置，界面/后台冻结观察。自身透明保护面允许透视，外层建筑玻璃、墙和楼板仍遮挡。仅记录“本次周期观察正常”。
- [固定保护面](../../../../src/examples/LighthouseCover.ts)位于原半径0.44米保护区内的南侧弧面：半径0.438米、±50.4°、高0.78米、中心在灯室楼面上1.21米。34顶点的固定弧面和24顶点擦布均为原创程序几何，盐膜采用细颗粒插值噪声/条纹GLSL，无新下载。擦布材质复用既有环境，动作工具不参加拾取或原静态阴影缓存。
- `check-cover`先现场确认固定轻度盐膜；仅自动日间待机可开始1.5活跃秒擦拭。动作期间显示擦布运动与中文进度，持续复核近距/面向/无遮挡和停机条件；开界面、失焦、走开/转头、爬梯、试灯或夜间起灯中断。取消无耗材和表面变更，提交前再次校验；成功后盐膜清除，出光游戏修正从0.82变为1，清单进入“已擦拭·待复查”。再现场确认洁净才通过检查。
- 原首层记录夹保留稳定标识`lighthouse-maintenance-log`和实体位置，改为动态中文会话记录，不克隆纸张或移动设备。显示本轮三项与完整摘要、最近运行事件、独立编号的观察/操作/日历事件、时刻/对象/来源，以及最近7日完成数。表面证据绑定修订号；清洁后原污损观察保留历史，当前必须复查。原时间/设置/地图与独立`lighthouse-panel`暂停、指针/ESC/Tab恢复保持。
- 仅运行模型的自动午夜推进值守日；重建三项待检查，保留洁净表面，次日直接检查即可。手动时间选点不增日或补发检查；刷新重建第1日12点和固定教学盐膜。跨会话保存留子项目二。
