# 岛屿景观第一阶段验收

日期：2026-10-23。源码基线`cb5b4b5`；最终实现见“增加岛屿第一阶段树林与远景林丘”提交。方案见[渐进实施计划](../../2026-10-23-island-background-landscape.md)。

## 已交付与成本

A屋后4个林团、24棵树；E三个低丘、48棵远树。原创程序几何固定种子231023；[几何记录](geometry.json)列出各区数量。新增10个静态网格、4,221顶点、6,432三角形和1个PBR材质；无新增下载素材/纹理/灯/相机/阴影目标。完整网格外廓位于现有可走区以北，树根和丘缘有实际三角面支撑。丘缘颜色过渡回原地表，不靠新增阴影或贴图遮接缝。

场景总网格716→726、顶点575,398→579,619、材质108→109；纹理153、灯22、相机3、带阴影灯19保持。上述为结构统计，不是GPU耗时或FPS测量。首轮三角面方向问题在浏览器检查中发现并修复，新增上下表面法线回归；树冠拓扑复用极点/环顶点，旧室外160,000顶点上限保持，不通过放宽阈值接纳景观。

## 工程与浏览器

- [415项测试](tests.log)、[类型检查](typecheck.log)、[开发构建](development-build.log)、[生产构建/发布校验](production-build.log)通过。四项新增测试覆盖完整外廓、地表/丘面射线、丘缘插值、面方向、阴影/碰撞/拾取排除、剖面隔离与幂等释放；骑行、梯子、原交互/存档采用全量已有测试回归。
- [浏览器脚本](check-browser.cjs)仅托管未修改的最终生产目录。通过调试器捕获既有实例，不注入新运行入口。固定机位视觉夹具暂时停用人物输入/重力回调，逐一核对相机实际位置；交互检查前恢复。尺寸切换先执行既有适配，再等待合成完成，避免旧尺寸画面残留。
- [修改前](before/browser.json)与[修改后](after/browser.json)保存全部请求、18组相机姿态、结构计数和结果：默认远景、阳台、门外向内陆、途中向塔、观景台回望、灯塔外廊；1280×800、390×844、844×390。姿态前后一致，三种远景尺寸的住宅/灯塔投影均在屏幕内。
- 同包正午/日落/午夜/雾/雨画面、拖动缩放、双地图、速度设置/重置、Inspector和`/home/`启动通过，无运行/着色器错误、404或控制台告警。Webpack三条原有体积建议保留。图片与渲染计数不能替代性能测量。
- [移动脚本](check-movement.cjs)与[结果](movement.json)独立使用原生键盘事件及60Hz参考相机步进，验证旧/新速度位移比1.3、默认/最高倍率护栏连续阻挡和倍率重置；不是实际旅程耗时或FPS实验。

## 包体与发布

| 两目标GLB | 4,332,840 B | 4,332,840 B |

原预算保持；最终首屏余11,144B、完整目录余345,611B。根和`/home/`各496文件逐个GET/字节/SHA256通过，[前清单](before/release-manifest.json)、[后清单](after/release-manifest.json)包括全部分包、来源说明与许可；运行素材摘要完全一致。

[第三次压缩试验](compression-candidate.log)仅回收113B静态JS，配置已撤回。[ES2020预检](es2020-precheck.log)在加景观前回收14,164B静态JS，最终景观接入后仍比基线少10,703B。未达到原争取24KiB回收目标，但缩小后的第一阶段满足全部原硬预算，因此未扩大优化范围。现有Babylon 9.30.0发布代码已经使用可选链/空值合并，项目对齐输出语法；无新依赖和功能删减。
