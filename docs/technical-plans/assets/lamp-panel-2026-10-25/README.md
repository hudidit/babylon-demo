# 大灯检查面板按钮补修验收（2026-10-25）

代码基线`cd5c978`；范围与实现见[一键检查补修方案](../../2026-10-23-lighthouse-simple-check.md#用户复测补修面板按钮静默失败2026-10-25)。用户确认入口为灯座面板的“检查大灯 · 3秒”按钮。

## 复现与修复

[原正常路径](before-normal.json)验证基线白天/夜间原生点击都能完成。[原低电路径](before-unavailable.json)以同一供电控制器合法初值200 Wh复现：面板提示仍是“留在灯旁3秒”，点击后面板关闭，但主灯不可用，检查未启动、没有原因。记录只说明这个失败路径成立，未断言用户当时的存档就是低电状态。新增拒绝单元测试在旧实现因`closed=1`而失败。

修复先在既有权限通过后尝试启动，成功才关闭面板并恢复环顾；失败保留面板，提示低电/恢复确认/隔离/驱动异常与可用的下一步。开始后的共享活跃时间、转动/出光证据、白天试灯所有权、夜间导航与存档格式不变；进行中恢复不重启计时。即时提示由现状快照生成，不改工作记录或消息原文。
