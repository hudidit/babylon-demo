## 验收内容

根/子路径最终结果与截图分别在 `browser/` 和 `browser-subpath/`：

1. 住宅入户门、灯塔门完全打开10活跃秒后关闭，暂停冻结，灯塔门关闭防夹、让开继续；灯塔门在外侧一米处能完整向内打开。
2. 中线及左右0.12m的三轮真实进出，无侧步修正；两层地图、E/W/S全程上/下16.10m、顶层玻璃出口/外廊往返。外观、首层、顶层和外廊截图检查材质、屋顶与净空。
3. 实际完成试灯一圈观察、保护面检查/清洁/复查及首层确认，保存并明确继续；镜头位置不是保存内容，当前人物仍留原处。
4. 原自动日界线到第4日保护面清洁到期一次、第6日太阳能到期；太阳能现场巡视、擦拭后仍需独立复查。到期后的精确回读第1日存档，恢复能量/证据/日序且暂停，不补算消耗；再保存内容逐字相同。
5. 存储写入拒绝仍可读取旧槽；未知版本不能继续或覆盖，明确清除才删除；刷新仍是默认正午自动新会话，明确继续才恢复已完成巡检并暂停。三视口无水平溢出，销毁后场景网格/材质/变换/灯全部释放。

纯模型测试另覆盖连续非整点时刻、7日日志、非法字段/越界/未来日序/交叉矛盾、损坏/超大/未来版本、不完成清洁/替换/补给不扣、已提交模块和燃料事务重复读写不重扣。四组复杂玩家入口仍备选，没有在本次恢复。

## 边界与诊断

- 验收前用NullEngine复现旧外开方向在外侧一米处42.9%就被防夹卡住，故灯塔改向内开；保留扫掠保护。初版浏览器将三轮进出当作同一次开门，第三轮已触发自动关门而受阻，脚本改为每轮等待关门并实际重新打开，不修改计时逻辑。
- 新梯位附近会优先触发爬梯；面板验收采用避开梯井/触发区的合法维护站位 `(-2.05,-0.8)m`（相对塔心），实际拾取面中心瞄准，保留原距离/遮挡和爬梯规则。
- 本次Chrome功能与视口模拟不扩大为WebKit/Firefox/Safari、物理手机、主观听感、三轮整应用重建、三条复杂维修演练或步骤五综合压力结论。它们的原历史记录仍保留；子项目二步骤五和天气随机机制仍待选。
