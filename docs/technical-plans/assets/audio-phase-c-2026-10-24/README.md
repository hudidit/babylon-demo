- [生成脚本](../../../../tools/prepare-soundscape-audio.py)、[原料档案](../../../../assets/audio-source/soundscape/README.md)、[逐文件清单](../../../../public/audio/soundscape/source.json)：8个AAC-LC循环、4个WAV短声，新增569,869 B、参考PCM13,355,520 B。两次生成全部13文件（含来源清单）SHA256一致。来源层级和作者合成/项目合成如实记录，不称为电驴或长海岸连续实录。

- 驾驶局部使用原生E/W/S/空格、地图与指针锁定；固定合法起点后调用原有`updateScooter`和`updateSoundscape`，不伪造速度。全路线由引导器只选择输入标志，使用原控制器固定1/60步，中途不改坐标/朝向。区域用合法站位隔离检查，未冒充人工全程驾驶、人工试听或加载/FPS实验。

## 浏览器结果

[完整记录](browser.json)已通过，包含以下边界：

- 无手势输出0、没有AAC循环请求；30个短音效/短循环、8长循环逐一测到非零且峰值<1的真实主输出。主输出测点在总音量之后，默认总音量50%、动作100%/环境70%/界面100%下验证，非扬声器到耳声压测量。
- 原生成功上下车各一次接触；实际起步/松键/急刹/倒车/地图通过，急刹一次、原地按键与障碍停稳不持续轰鸣。电机原生AudioBufferSourceNode速率约1.138→1.318，播放次数仍1；跟车偏移由转头/真实车头方向推导并限幅±0.18，不做Doppler。
- 不改变中途姿态的原控制器路线到塔前185.638m，1,550个固定1/60步。四天气、住宅、塔底、灯室、外廊、太阳能露天点分别检查；解析区域而非逐声源射线。另按真实音频时钟逐40ms更新1.8秒入屋渐变，露天雨降低、遮蔽雨保留。阳台/外廊遵循当前雨棚防穿雨范围，风与雨的遮蔽比例不同。
- 8循环同时保留16.5秒，覆盖最长8秒循环至少两圈，声部不重启；原生解码缓冲没有100ms全零窗口，PCM实测14,578,560 B与发布清单一致，符合16 MiB上限。默认音量下混合输出峰值约0.0185；数据只证明连续输出/余量，不证明音色好听或所有接缝不可闻。
- 原生设置操作验证环境归0仍有实物动作、动作归0仍能试听界面、界面归0试听为0；旧enabled/volume兼容、分组存储与重载通过。1280×800、390×844、844×390设置均在视口内、无横向溢出；低高度允许面板纵向滚动。
- 地图降低环境且停车；设置/Inspector世界输出0。失焦/隐藏为0活动声部、所有原生循环已stop、AudioContext suspended，恢复从当前快照重建，不补旧动作。**暂停分析器保留末帧**，`frozenAnalyserPeak`不作为仍在后台发声的证据；通过context与原生source状态区分。销毁后context closed，分组重载与静音刷新通过；静音刷新0 context、0音频请求。
- 新页面独立阻断`wind-open`，只请求2次后降级；其余30短声和海浪就绪、海浪继续，场景不阻塞。正常主路径错误0；受控404单独登记。保留Inspector原有非标准`slider-vertical` CSS提醒1条，Webpack3条体积建议；未写零告警。
- 完整528文件根路径与`/audio-lab/`子路径逐项HTTP/字节/SHA256通过，包含所有动态分包、许可、来源、清单自身。首屏已含必需异步和立体声模块；首屏外新增JS路径记录在[容量表](capacity.json)，没有隐藏Inspector成本。
