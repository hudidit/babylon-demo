## 实现与验证范围

- 晴朗/阴天/海雾/风雨统一影响天空云色/云量、自然光、海面、空间雾和现有双卫镜面；人工灯开关/强度保持。雾用世界距离和反射眼位计算，天空背景的大气路径属于美术近似。有限雨线为1网格、576顶点、1材质的程序几何，按宅内/塔内/机房柱状空间遮蔽，没有新纹理、灯、相机、RTT、音频或下载；减少雨线动态不关闭天气和设备机制。
- 当前时间菜单增加固定工况与自动天气。自动变化继续使用共享接受时钟和原20参考活跃秒过渡；固定选点不重置设备、库存和问题。固定天气是当前会话的环境选点，固定种子/独立演练保存的隔离仍属步骤四，未提前交付。
- 原生产桥接按天气边界及2/3km门限/10分钟恢复拆分，解析积分日照×线性天气倍率。海雾白天真实请求导航及55W主支路负载；阴天/风雨低输入不单独请求导航。天气问题、教学/到期污损与真实修订、功率和清洁复查同源，自动污损不会被记录成一次玩家巡视。
- 风雨暂停新的室外擦拭，正在进行的动作中断，表面和物料不改；室内读数/保护面清洁和全部通道保持。菜单返回后的画布点击先恢复键盘焦点，再请求指针锁；原生W键撤回不使用手工focus或位置纠正。
- 版本1只保存设备、真实Wh、时刻及历史。界面在保存前明确天气仅本次会话；继续时天气重新开始且时钟先暂停。保存副本移除瞬态天气请求，当前会话不改；分段末端精确对齐接受时刻，不放宽版本1严格一致性校验。天气/问题/随机完整存档迁移仍属步骤四。

## 方法、复跑与诊断

- 仅托管最终dist，运行[serve-dist.cjs](serve-dist.cjs)，监听本机8254，支持根及`/home/`；没有用开发服务器补齐素材。临时独立浏览器上下文不读取用户账户。
- 工程命令按`npm test`、`npm run typecheck`、`npm run build -- --output-path /private/tmp/lighthouse-weather-step2-development`、`npm run build:production`执行；日志只清理行尾空白和末尾空行。
- 执行[make-due-slot.cjs](make-due-slot.cjs)可从原有健康80%设备模型，以64,800个有界0.1秒接受凭据自然推进到第6日，再手动选正午；生成[合法版本1夹具](solar-due-slot.json)及[来源记录](due-slot.json)。最终work从原生“继续”载入该档，不把夹具加载算成浏览器已走6日。早期现场另实际推进64,801个生产回调到第6日并完成风雨取消，但随后夹具少等了太阳能的2秒动作而失败；完整诊断保存在`diagnostics/work-natural-day6.json`，没有计为完整通过。
- 设置`PLAYWRIGHT_PACKAGE`到`playwright-core`，`PLAYWRIGHT_BROWSERS_PATH`指向匹配的WebKit目录，再运行`node run-checks.cjs`，最后`node verify-evidence.cjs`。本机测试依赖为临时目录中的Playwright1.64.1及匹配WebKit，不进入项目依赖/发布。参考输入固定50ms和20fps仅用于原相机运动公式的可复现步进，不是帧率采样。
- 镜面公共`readPixels()`在本机返回null；改用真实显示镜面面片内的主帧GPU像素，并复用原窗口云像素和无窗遮挡断言。没有把空读回当成反射没有变化，也没有用全屏颜色变化替代原反射专项。
- 指针锁/键盘焦点初次导致原生W未进入输入监听：产品修复画布点击恢复焦点，最终不调用测试手工focus。太阳能动作按原完整2秒验收；没有缩短动作或放宽成功条件。

本步没有Firefox/Safari/物理设备、真实气象/航标射程、FPS/加载速度或多日未知玩法平衡结论。预报/发现缓存留步骤三，完整随机存档与演练隔离留步骤四，统计平衡及综合发布留步骤五。
