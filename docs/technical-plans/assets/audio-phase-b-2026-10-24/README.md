# 声音阶段 B 验收（2026-10-24）

基线`3ad2d8e`，Babylon 9.30.0，Chrome 155.0.8059.86 / macOS。本阶段工程与Chrome验收完成，人工听感/其他平台待验；电驴与天气未接入。总体设计与实施取舍见[声音方案第14节](../../2026-10-24-game-soundscape-expansion.md#14-阶段b实施记录2026-10-24)。

## 交付与复现

- [原料/许可档案](../../../../assets/audio-source/actions/README.md)、[逐文件清单](../../../../public/audio/actions/source.json)、[生成脚本](../../../../tools/prepare-action-audio.py)：14个单声道PCM16/48kHz WAV，325,096 B，新增PCM648,960 B。两次生成全部15个文件（含清单）SHA256一致。Ogg交付和公共HQ MP3预览的层级如实记录，不称为无损原件。
- [自动化浏览器脚本](../../../../tools/check-action-audio.cjs)：先运行`npm run build:production`，再运行`node tools/check-action-audio.cjs`。可用`PLAYWRIGHT_PACKAGE`指定Playwright Core位置；脚本默认使用本机Chrome，托管服务器只读dist并在结束后关闭。生产包未改写，debugger只捕获已有RoomScene。包装已准备AudioVoice的play方法仅记录真实调用，原生AudioNode主输出旁路在总增益之后采样。
- 清洁使用原生按钮、指针锁定和现有`updateTimeOfDay(.05)`接受回执，近处姿态由场景坐标固定；为避免等待数个游戏日，仅太阳能表面通过现有`soilFromWeather()`种入一次天气污损，再原生巡视/擦拭。没有修改污损/修订/清洁时间或写入伪造完成证据。关闭渲染循环是测试受控推进，不是FPS或加载耗时测量。
