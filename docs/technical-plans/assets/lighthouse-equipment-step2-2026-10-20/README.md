## 复跑

先完成`npm test`、`npm run typecheck`、`npm run build`，最后执行`npm run build:production`。仅将最终`dist`通过[独立服务器](../coastal-cliff-d-2026-10-18/serve-dist.py)托管到8220端口，保留根路径和`home/`子路径。

设置`PLAYWRIGHT_PACKAGE`为可用的Playwright包，`PLAYWRIGHT_WEBKIT_EXECUTABLE`为对应WebKit执行入口，然后运行：

```sh
node docs/technical-plans/assets/lighthouse-equipment-step2-2026-10-20/run-checks.cjs
node docs/technical-plans/assets/lighthouse-equipment-step2-2026-10-20/verify-evidence.cjs
```

可为第一个命令传入套件名进行单项复跑。每项结果绑定生产清单、脚本和适配器摘要；生产包变化必须新建记录，不能拼接旧包的通过项。工程原始输出保存为本目录的四个日志。

## 方法与边界

- [三条演练](check-drills.cjs)仅用近处落地站位夹具定位设备；所有命令、工具选择、取消和恢复均经过实际鼠标/原生界面、距离/遮挡检查和原生产帧回调，不写入故障、备件、证据或设备状态。参考帧采用50ms有界活跃凭据，截图期间冻结增量；它不是耗时、加载或FPS测量。
- 根/子路径均完整处理驱动、充电和光敏三条路径，包含实际备用白闪GPU像素、主灯隔离/试机/恢复、中断与错误工具、替换后重新检测、真实5秒检验回路净Wh及撤销人工覆盖。原值守中的试灯余时、时刻、巡检、库存和维护对象退出演练后按原值恢复。
- [设备适配器](equipment-adapter.cjs)保留步骤一的设备实点、机房通行、真实W键阻挡和各视口布局检查，更新八个设备、24网格/1,588顶点、已接入状态及多控件Tab循环。[回归适配器](suite-adapter.cjs)复用旧巡检/连续住宅往返/五层/外廊、住宅门灯帘/双卫反射及车辆车灯套件，仅更新数量/输出目录并保留原截图冻结修正。
- [GPU矩阵](check-matrix.cjs)覆盖Chrome/WebKit、DPR1/2、桌面/竖屏/横屏的六类设备原材质显隐对比，共72项；含新增光敏保护面。[回归适配器](suite-adapter.cjs)额外执行Chrome三轮应用重建，逐轮检查15个命令按钮及销毁后0按钮、监听和全部渲染资源释放。[发布检查](check-release.cjs)逐项核对根/子路径的全部文件GET、字节与SHA256，并比较36个运行素材与步骤一一致。
- 浏览器环境为Chrome155.0.8059.85与Playwright WebKit27.2；完整演练和应用重建使用Chrome，WebKit检查设备GPU矩阵。Firefox、Safari、物理设备和多日压力本步未重验。原性能实验保持暂停，不声明FPS、加载速度、耗时或实际航海射程改善。充电采样来自标准检验回路，不是主电池存能；完整电池/燃料和保存待步骤三/四。

## 诊断留档

[attempts](attempts/)保留首次首层无效站位、原生指针锁恢复未稳定时点击选错入口、以及主灯正前方固定支撑遮挡的失败结果。后续采用已有首层/灯座站位、等待原生锁恢复，再从侧方避开支撑观察主灯；实际距离、遮挡、计时和复验断言保持。失败结果不计入最终通过项。

`pre-lifecycle-qa/`仅保留前一生产包14套预验的汇总/发布摘要，原脚本报告所引用的结果路径已由最终验收重写，不能将该摘要当作可独立复核的最终证据。代码复查发现新增命令按钮需要随面板销毁清理，修复后重新构建，最终15套全部重跑；同时补充备用状态修订清除旧累计、对话框重新打开回顶部及已确认备用的现场提示。
