# 小电驴夜间前照灯验收

日期：2026-10-20。代码基线：`1f873d0`。对应[技术方案](../../2026-10-20-scooter-headlight.md)。使用Babylon 9.30、原依赖/素材/发布白名单。无FPS、GPU耗时或加载速度采样。

## 功能与画面

- [Chrome记录](browser.json)：真实E上车、W加速（1.875 m/s、行驶0.711m）与空格刹车时夜间自动亮灯；默认/白天/未骑乘关闭。T菜单真实选择12/0点，过渡强度包含中间值并抵达8；地图/设置保留灯，切预设关闭/返回恢复，模拟visibility事件立即关闭/恢复，回到已验证家门停车位E安全下车关闭，主动回家关闭。
- [亮灯](night-riding.jpg)与[同位关灯参考](night-reference-off.jpg)：同一午夜/相机/路面区域读取实际颜色缓冲，平均亮度19.094→17.434；此处只验证路面受光，不用于性能结论。[转向](night-steering.jpg)中灯方向随车头变化，鼠标转头不改变光向。[正午骑乘](noon-riding.jpg)保持灯灭。
- 38个室外接收网格，天空/海面/远景/车辆及住宅、灯塔内部排除。只新增1盏无阴影SpotLight；无额外纹理、阴影目标或RTT。初始低指数光束出现硬圈，最终改指数32/外角1.1弧度/强度8后已检查软边画面。
- [双引擎记录](engines/matrix.json)：Chrome155.0.8059.82、Playwright WebKit26.5，1280×800/390×844/844×390，DPR1/2共12组；实际渲染尺寸随DPR变化，逐组路面亮灯亮度高于同位关灯，三种车辆材质就绪，页面销毁清零。矩阵采用固定相机/灯光夹具并暂停Room帧回调；真实自动控制和驾驶由前述Chrome套件验证，不能把矩阵记为12组真实驾驶。截图见`engines/`。
- [原功能回归](regression.json)：38动作、8抽屉/8原灯/7门/推拉门、55段全屋通行、地图/详情/设置/Inspector及销毁通过。额外四盏主灯/六窗动作计入原集合，未新增车灯开关动作。新车灯生命周期和灯塔工作灯隔离另有单元测试。
