## 实际实现

- 左下帮助、时间入口、视角栏自然堆叠，八节点两列单选，常驻时间文字和独立自动开关。桌面面板向上展开；窄屏/矮屏面板最高60%视口，可滚动且关闭按钮吸顶，暂隐视角、小地图和帮助。选项至少44px，支持ARIA/Tab/方向/Home/End/Enter/空格及触控，无图片、图标包或额外依赖。
- 手动从已显示快照用1.2秒缓入缓出到最新目标，连续改选取消旧目标。昼夜换源在零强度处改方向，再渐入目标，天空/海面/环境同步；天空暖色方向单独连续处理，避免暗光换源时暖色地平线跳变。减少动态效果用0.2秒淡出/淡入并在暗处改向。原立即选点接口保持兼容。
- 自动默认关闭，每现实秒推进1/60场景小时，24分钟回卷；点击节点关闭自动，停止停在连续小时。混合快照不是某个实际连续轨迹时刻，所以过渡中主动开启自动会先完成短过渡，再从目标继续。自然光及对应阴影、天空/海面统一最高10Hz；手动期间逐帧刷新自然阴影，人工灯缓存保持独立，停止补齐最终状态。
- 时间菜单、设置、地图、详情、Inspector、失焦、隐藏、兼容外部控制分别持有暂停原因；关闭一个原因不会恢复另一个仍占用的控制。时间菜单内手动过渡可完成，其他暂停冻结过渡。delta上限0.1秒，恢复首帧不累计后台时间。打开前登记暂停、清空输入并释放锁定；关闭时间菜单保留步行/骑乘/梯上姿态，再点击场景恢复。Inspector异步初始化和内部隐藏均纳入暂停，事件/订阅随场景销毁清理。
