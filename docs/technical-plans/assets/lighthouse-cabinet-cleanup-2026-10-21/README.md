- Chrome155.0.8059.85、Playwright Core1.64.1、1280×800/DPR1、禁用缓存/ServiceWorker；独立静态服务器只托管`dist`。CDP仅捕获原Room实例，机位设置合法落脚高度3.54m，实际渲染截图；未修改设备/库存/碰撞或生产代码。
- 根/子路径均通过原生指针锁定和鼠标实际打开太阳能充电控制器、主电池配电柜，返回继续场景；读数和局部仪表正常。浏览器零错误、零告警、零404。修复后脚本主动刷新地图HUD，修复前相机机位记录未刷新地图；这不是地图功能改动或地图对比结论。
