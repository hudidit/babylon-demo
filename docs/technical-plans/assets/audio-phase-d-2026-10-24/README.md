- 先`npm run build:production`，再`node tools/check-daily-audio.cjs`运行[独立检查](../../../../tools/check-daily-audio.cjs)。Playwright Core可用`PLAYWRIGHT_PACKAGE`指定，默认本机Chrome；只托管dist，完整根/子路径校验，不修改生产包、不以开发目录补缺文件。结束关闭浏览器和服务器。
- debugger只捕获既有RoomScene；AudioVoice包装记录实际播放/停止，原生AudioNode测点在主音量之后。逐缓冲直接调用已准备的真实Audio V2声部检查75文件，然后用真实事件路径单独验证素材选择、暂停与语义；不把逐文件试播当作事件接线证据。
- 原生W/Space/E/左键/J/M及按钮驱动实际相机碰撞、跳跃、梯子、车辆与交互；合法起点用于隔离材质，途中不改位移、速度或高度。渲染采用固定接受步长，不是人工全程试玩、行程耗时或FPS实验。布帘移动后重新瞄准当前可见三角形；没有直接调用toggle冒充原生点击。

## 工程和浏览器结果

[457测试](tests.log)、[类型](typecheck.log)、[开发构建](development.log)、[生产构建及发布检查](production.log)通过。覆盖实际位移/腾空/落地、材质/地毯/软座、传送/卡顿/重置、梯级上下行、窗帘取消/反向、转台运行/暂停、四变化可选/不紧邻重复、空间持续声定位、分组静音及来源/许可/摘要/预算失败路径。

[完整浏览器记录](browser.json)通过：

- 无手势主输出0、无AAC请求。75个缓冲逐一非零且峰值<1，全部原生解码计16,448,640 B，与发布清单相同；PCM并非进程总内存。默认总音量50%，各组输出按实际设置，测量不代表到耳声压。
- 木、软面、金属、土质与硬地原生步行均有对应脚步；每次原生跳跃只落地一次，腾空没有步声。持续顶墙位置稳定且无声；实际骑乘行驶（测点1.667m/s）与制动无脚步/落地/梯级声。
- 原生上梯、爬升、停梯、下降、到顶和离梯通过；中途离梯被拒时保持附梯、无成功接触。窗帘进度0.392时原生反向，旧声停、新声一次、端点回0；地图中断停止布帘与脚下声，恢复不补历史接触。
- 夜间自动走时关闭，转台仍实际运行；4.5秒覆盖2秒循环至少两圈，声部没有重启，近场输出非零且未削波。地图停声与恢复、白天停灯、试灯成功/重复拒绝/结束通过。低电使用同一生产供电控制器的200Wh合法初值夹具，经正常同步得到protected=true/主灯停机；不声称实测了长时间电池耗尽。
- J打开/收起簿子各一次纸声；有效故事切页3声、重复页0声。设备页为轻UI、日志为纸张，打开运行面板与读页不误发实体switch；动作静音仍可试听UI，UI归0主输出0。悬停、滚动和隐藏刷新不绑声音。
- Inspector动态加载通过且世界输出0。失焦事件路径：0活动、原生循环全stop、context suspended；销毁后closed。原生OS切窗、其他设备/平台未验，不由事件注入推定已通过实机后台行为。
