# 第一人称提速与家具跳跃验收

2026-10-17，代码基线`1e007cf`，对应[第一人称提速与家具跳跃方案](../../2026-10-17-first-person-jump.md)。

## 实际交付

- [Room](../../../../src/examples/Room.ts)第一人称基础速度`MOVEMENT_SPEED.base`从0.55提升到0.825（+50%）；设置面板的0.25～3倍率、WASD/方向键、惯性和碰撞不变。
- 新增[HouseJump](../../../../src/examples/HouseJump.ts)：以米为单位的脚高/垂直速度状态、9.81m/s²重力、0.72m最大地板跳高、0.3m边缘攀上辅助、0.08m阻挡外扩和按净高动态限高；空中不能二段跳。
- 空格键在`keydown`（非repeat）请求跳跃，地图/物品查看或设置面板中不触发；第一人称提示和鼠标未锁定提示均加入“空格跳跃”。
- 可着陆白名单：客厅主沙发0.441m、阅读沙发0.46m、阅读扶手椅0.48m、书房椅0.561m、茶几0.468m、主/次卧床0.73m（折叠毯顶面，避免站在毯子侧面的碰撞体内）、次卧窗下阅读凳0.5m。
- 平台边缘按0.26m玩家半径保留支撑；起跳/离开平台记录`originTop`，攀上辅助只作用于更高的平台，不会把刚走下平台的人吸回。
- 书桌、窗边控制台、古董柜和床头柜登记为不可进入/站立的blocker；阳台栏杆、外墙和L形室外边界继续使用原碰撞与水平边界，跳跃高度0.72m低于栏杆1.1m。
- 水平碰撞仍由Babylon相机碰撞完成，垂直只覆盖相机Y；进入/重进第一人称重置到地面，退出和模态期间停止垂直推进。

## 边界与复现

- 导入沙发/扶手椅的座面高度采用0.46/0.48m美术高度；模型总包围盒约0.76/0.95m，若后续更换模型需要同步平台表。
- 本轮没有跳跃动画、落地音效、二段跳、移动端触摸跳跃或户外行走；阳台/室外仍安全封闭。
- 固定50ms采样和传送落点只验证功能/高度，不是FPS、加载耗时或GPU性能测量；实机指针锁定漫游和DPR2仍待后续平台验收。

复现：

```sh
npm test
npm run typecheck
npm run build -- --output-path /tmp/jump-development
npm run build:production
python3 -m http.server 8113 --bind 127.0.0.1 --directory dist
```

