2026-10-18，基于`66221d4`（小电驴V1～V3交付）验证用户反馈的两项操作调整：最高速度从18 km/h提高到40 km/h，A/D转向偏航响应降低50%。对应[载具方案](../../2026-10-18-coastal-electric-scooter.md)第9节；此前的V1～V3完整验收保留在[原验收目录](../coastal-scooter-2026-10-18/README.md)，不覆盖其历史数据。

## 浏览器检查

[验收脚本](check-tuning.cjs)在生产`dist`、Chrome正常渲染循环和真实W/A/D/Space按键下运行；仅在两个隔离参数探针中放置骑手位置，路线往返期间不直接赋车辆位置或朝向。测试桩为原有场景调试捕获，未修改交付包。

- 最高速度：从静止加速约4.57秒达到11.111 m/s，HUD显示“骑行 40 km/h”，10个采样均在有效支撑上，[截图](top-speed-40.jpg)。
- 转向：停稳满舵按D 1秒，航向变化0.7694 rad（44.08°），按同一基础响应推算调整前约88.17°，比例0.5；旋转后车辆仍在有效支撑上。
- 往返通行：真实按键完成家门→灯塔前场[32.96秒](ride-home-to-lighthouse.jpg)和灯塔前场→家门[28.95秒](ride-lighthouse-to-home.jpg)；计时包含脚本终点2秒刹停，沿途每约0.48秒采样均通过完整外廓支撑。塔前真实A键原地调头3.94秒，两程最高速度均达到40 km/h。
- [浏览器记录](tuning.json)无页面错误、警告或4xx响应；[运行日志](browser.log)。

## 边界与遗留

本次是操作参数调参，不是FPS、加载速度或网络性能收益。Chrome真实指针锁定驾驶已验证；WebKit完整驾驶、Firefox/Safari、物理设备、完整旧平台矩阵和全部旧交互专项未在本轮重跑，原V1～V3记录继续作为其历史依据。高速度下急弯仍需主动刹车，限速区逻辑和弯道半径未调整；如后续反馈转向仍偏灵敏或高速过弯困难，应另立调参与安全验收，不据此修改本记录。
