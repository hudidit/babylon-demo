## 背景与现状

现有统一射线交互支持八个抽屉与两盏灯。桌上的信具有独立褶皱几何和原创动态文字贴图，但最终合并为静态材质网格，不能单独点击或查看。第一人称使用 Pointer Lock，详情界面必须协调鼠标释放、暂停输入、返回时的相机与位置恢复。

## 目标与范围

- 点击桌上的信（环绕视角或第一人称中心射线），在屏幕中央以固定正面角度放大展示同一物品，下方提供“返回”按钮。
- 查看期间禁止镜头旋转、移动、缩放、穿透操作和视角切换，释放鼠标方便点击按钮，隐藏中心圆点与场景工具；ESC 也可返回。
- 返回后保留原相机、位置、朝向、视角选择、灯光与抽屉状态；第一人称通过按钮返回时尝试恢复鼠标锁定，拒绝时保留点击重试路径，ESC 返回不立即强制重锁。
- 建立显式可查看物品注册，本轮仅注册桌上的信，不自动给所有家具增加详情。
- 沿用现有几何、贴图、pure 导入及预算，不添加依赖、外部素材或第二个引擎。

## 方案与取舍

1. 信件从全室静态合并中单独保留，原尺寸、褶皱、UV、桌面位置及阴影不变；统一交互注册增加查看动作，继续检查遮挡、距离和拖动误触。
2. 同一场景内增加不附加输入的固定正交相机，使用独立 layerMask 只呈现详情副本。副本共享原几何和动态文字贴图，独立不受灯光影响的展示材质保证文字可读；复用既有最终后期，原场景及相机姿态保持不变。副本不参与拾取、碰撞和阴影，退出后销毁副本/展示材质，保留共享资源。
3. 用原生模态 dialog 管理焦点与底层 UI 隔离。进入查看后暂停相机输入、物品动作和抽屉动画，释放指针；返回恢复原相机，不调用会重置位置的视角预设。按窗口宽高适配展示大小与返回按钮位置。
4. 增加必要状态保护，避免锁定释放事件被解释为退出第一人称，ESC 一次只退出详情。关闭与销毁清理监听及预览资源。

## 验收方法

- 几何测试：原信件仍贴合桌面，详情副本共享几何/贴图且不改原件变换；相机正对物品且无输入，横/竖屏完整呈现；多次开关无网格/材质泄漏，不销毁共享资源。
- 浏览器：两种视角真实点击信件、居中且文字方向正确、鼠标/WASD/方向键/滚轮不改变固定镜头或原场景、Tab 焦点留在返回按钮；按钮/ESC 返回、原位置/朝向及第一人称锁定恢复/拒绝/失焦路径，移动后进入详情再返回不传送。
- 回归：八个抽屉、两灯、中心交互、ESC 退出第一人称、视角/拖动/缩放、设置及 Inspector；独立托管检查无新增运行/着色器错误或 404、完整动态分包可访问。
- 资源 ≤16 MiB、目标 GLB ≤4.25 MiB、静态与实际首屏 JS ≤3 MiB、完整发布目录 ≤41 MiB。保存当次清单及浏览器结果，不进行 FPS 或加载耗时采样。

## 参考与结果

核对本地固定版本 `camera.pure` 的 layerMask/正交参数、`mesh.pure` 克隆共享几何、`StandardMaterial` 发光贴图与既有后期链。实现沿用 pure 导入，无新增运行注册或素材。StandardMaterial 发光色采用黑色（该材质把常量发光色与纹理相加，白色会把文字冲白），保留原贴图的旋转参数并校准副本朝向，确保文字正确显示；不修改桌上原件。

## 实际结果与交付

- 注册了桌上的信，详情复用原几何与动态贴图；固定正交相机使用独立图层，原相机、灯光、物品状态保持不变。底层相机输入和抽屉动画暂停，模态 dialog 隔离场景按钮与焦点。
- 桌面/横竖屏居中完整呈现，物品下方返回按钮可用。按钮返回恢复原相机/位置/朝向，第一人称尝试恢复锁定；ESC 只关闭详情，保留再次点击重锁或退出第一人称的路径。模拟锁定拒绝、失焦和重试通过。
- 41 项测试、类型检查、开发/生产构建及发布校验通过；独立 pure 进程检验共享几何/贴图与清理。浏览器检查真实点击、固定镜头/输入隔离、原相机恢复和重复开关的资源数量；八个抽屉、两灯、第一人称、视角/拖动/缩放、设置与 Inspector 全部回归通过。
- 462 个发布文件逐个托管 GET 与 SHA256 核验通过；18 个运行素材摘要不变。实际首屏 JS 含必要异步为 2,600,750 字节 / 2.48 MiB（增加 4,757 字节），完整发布 42,040,871 字节 / 40.09 MiB（增加 6,263 字节）；全部预算满足，无新增依赖/素材。浏览器无运行/着色器错误或 404，构建保留三类既有建议告警。
- [验收记录、截图、请求、脚本及发布清单](assets/item-inspection-2026-10-16/README.md) 与实现、测试、索引和变更日志同一提交交付，标识通过本文件 Git 历史追溯。

本轮仅注册信件；后续物品须显式注册并提供合适展示朝向。新增固定相机复用现有后期，详情副本和展示材质退出即释放，共享资源保留。本轮不采样 FPS 或加载耗时，也不宣称性能收益；其他浏览器未实测，既有亮屏性能验收保持待完成。
