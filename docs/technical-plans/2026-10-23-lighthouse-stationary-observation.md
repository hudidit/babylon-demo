# 原地观察完整灯具

状态：普通巡视已由[大灯一键检查](2026-10-23-lighthouse-simple-check.md)替代；历史交付与复测记录保留。创建及更新：2026-10-23。输入基线：原交付`3dc759d`，本次补修`3d0ddf4`。相关方案：[30秒周期与白天试灯](2026-10-22-island-overview-and-beacon-timing.md)、[首轮巡视](2026-10-20-lighthouse-focused-experience.md)。遵循[资源原则](../resource-optimization-principles.md)及[文案规范](../game-writing-guide.md)。

## 背景与目标

用户实际开启试灯后，只有对准转动的发光部分才累计观察，绕行又被梯子阻挡。此前安全站位的工程检查不能代表普通玩家的站位；仅补充“白天先试灯”无法解决可完成性问题。

当前观察复用了近距离设备操作判定：1.5米、准星附近的射线，且目标网格随灯头转动。新判定应让玩家站在灯室内，看灯具整体完成观察，不用追逐发光面或绕灯走动。

## 方案及取舍

- 主灯观察独立于设备按钮和擦拭：距离放宽至3米，完整灯具进入相机视野即可；用围绕固定灯头中心的多条视线验证可见性，任一真实灯具表面可见即累计。忽略原透明保护面及非实体空气光束，实体墙、玻璃、楼板或完整遮挡仍阻断。
- 30秒与一圈继续读取真实运行时钟及转台相位；光束扫过固定观察者时记下真实出光。灯转向别处、瞬间不发光不会重置观察，不要求玩家追光。
- 保留停灯、离开顶层、看开、完全遮挡时重置，菜单/失焦暂停冻结且不补时；爬梯、骑行、空中及远景不能取证。设备按钮/清洁继续沿用原近距授权。
- 更新任务单、现场提示和进度说明，明确白天60秒试灯和原地观察整体灯具；不放宽30秒/一圈/真实出光三项要求，不修改存档格式、稳定ID或历史证据。
- 同包首屏预算余量很小；若新增判定超预算，优先复用已计算的出光结果、提取重复提示/可见性逻辑，记录实际字节，不提高预算或漏计异步JS。

## 实施和验收

1. 实现独立观察判定，避免设备操作距离/准星和旋转局部表面的耦合；补充场景几何测试。
2. 在多个可走方位和距离，固定位置/朝向跨完整旋转周期；测试灯具在视野边缘仍可观察，背向/离层/停灯/全遮挡/无出光不完成，暂停不补算。
3. 最终生产 Chrome 用原生试灯按钮，固定位置和朝向，仅推进真实共享时钟，29.9秒未完成、30秒一圈且见过出光后完成，并核对故事清单。手机/桌面文案可读。
4. 全量测试、类型/开发/生产构建、独立根/子路径发布和首屏检查；同步方案、索引及 CHANGELOG，提交推送。

## 实际结果

主灯观察已独立为 `canObserveMain`：灯具中心的固定四点分布在三个空间方向，偏移各0.16米，不随光头旋转；相机视锥包含灯具、3米内至少一条射线命中真实灯具表面即可累计。透明保护面与非实体空气光束不阻挡，实体完全遮挡仍失败。3米按可见表面射线命中距离核对，设备按钮/擦拭权限保持原近距判定。出光复用本帧已有的方向光强并计入真实保护面透射，转向别处不会重置已见过出光的记录。

- 新增几何回归覆盖半径1.2/1.6米的13个可走位置，各固定朝向取32个转动相位，共416个可见性样本；灯具偏离准星约0.5弧度时仍可观察。背向、全遮挡、远处/外玻璃、离层、空中、梯上、车辆、远景和暂停均拒绝。保留原无出光/冻结转台/相位跳变/中断/暂停不补时测试，新增整周期只看到一次短暂闪光仍可完成的测试。
- Chrome155最终生产包：正午晴朗，从顶层实际试灯控制及正式按钮开启60秒试灯；随后在距灯头中心约1.67米的站位固定位置和朝向，直接推进共享时钟。29.9秒为0.9967圈且未确认，30秒为1圈、已见真实出光，检查与第一章 `main` 清单同时完成，尚余30秒试灯时间；全过程未追光或移动。此为固定站位回调验收，不等同于30秒墙钟/完整首玩时长测试。
- 任务单、第一章下一步、设备现场说明明确白天试灯和原地看整体灯具；桌面与手机文字可读。稳定ID、消息原文、存档格式与历史证据保持。
- 全量395测试、类型/开发/生产构建、自动发布及根/子路径各496文件GET/长度/SHA256通过。曾测得候选首屏超预算197B，随后复用出光结果、提取重复移动提示、将固定采样收敛为四点并精简重复提示；没有改阈值或漏计异步文件。最终实际首屏含必需异步JS为3,145,717B，比3MiB预算少11B；静态初始JS2,926,865B、完整发布42,655,639B，两目标GLB4,332,840B、36素材15,867,377B。首屏余量很小，后续新增功能需继续检查。相对输入首屏增加501B、完整发布增加1,675B，仅报告字节变化。

[联合验收证据](assets/player-controls-2026-10-23/README.md)保存脚本、请求、源摘要和近景。浏览器无运行错误/404/告警，生产构建沿用三条webpack体积建议；本次未复验Inspector、其他浏览器、物理设备、完整路线或性能。此前单一安全站位的历史记录保留，不能据此宣称所有站位原已可完成。实现提交通过本文件和 CHANGELOG 的 Git 历史定位，提交目的“修复探索切换与灯塔面板和观察交互”。

## 用户复测：看灯无触发提示（已替代）

用户反馈光标对准灯具仍没有任务提示。扩充原几何探针后复现：外廊半径2.5/2.8米，各24个可走方位中只有3个能启动观察，其余21个被肉眼透明的`coastal-lighthouse-glazing`玻璃拦截。原验收只覆盖灯室内13个站位，并把外玻璃当成操作遮挡；将操作权限直接沿用到视觉观察不合理。另有静止待机时没有解释、观察进度仍提示“保持准星对准”的反馈遗漏。

本次替代上文“外玻璃阻断观察”的限定：只在看灯射线中透过指定透明灯室玻璃和已有保护面，实体框柱/梯子/墙/楼板仍遮挡，按钮与清洁仍不能隔玻璃操作。保留3米、顶层、第一人称、30秒/真实一圈/见过出光及暂停规则。补上观察启动/停灯需试灯提示，圆环说明改为看灯具整体、不追光。已完成检查不反复触发。

实施顺序：先覆盖外廊透明玻璃前后的失败路径，再修正视觉谓词与提示；验证真实场景模型的完整相位、部分/完全遮挡、3米边界与原设备权限。最终dist单独校验首页、资源及预算；同一源码另建不进入发布目录的站位夹具，在前台浏览器观察实际进度DOM与真实30秒计时。夹具仅设定站位/朝向和合法行走高度，不替换delta、运行相位或任务证据，不以直接快进共享回调代替墙钟观察。包校验与夹具验证分别记录，不将程序站位写成完整徒步通关。首屏现余316B，保持原预算；新增提示尽量简短，不提高阈值。

该补修未独立完成浏览器验收，已由下述一键检查方案整合与替代。
