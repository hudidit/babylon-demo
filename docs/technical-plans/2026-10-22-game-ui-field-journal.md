## 设计说明与方案复核

游戏是安静的孤岛值守叙事。以海角灯站的值守簿、纸面交接信和岸站文字联络组织界面；只在入口使用原创灯塔线描作为主视觉，其余区域服务阅读与行动。

| Token | 值与用途 |
| --- | --- |
| 海墨 | `#183238`，封皮/导航/任务HUD |
| 深海 | `#10252b`，背景与层级 |
| 雾纸 | `#e8e9df`，内页阅读面 |
| 黄铜 | `#c7b17b`，当前选择与主行动 |
| 石青 | `#607979`，辅助信息/分隔 |
| 锈红 | `#8c3e2f`，清除不可用存档等需处理状态，搭配明确文字 |
| 字体 | 宋体系统回退用于篇名；系统无衬线用于操作/状态；交接信保留楷体回退，不下载字体 |

布局草案：

```text
入口：故事标题/开始与继续       灯塔线描
游戏中：页签导航 | 当前内页（任务 / 信件 / 联络 / 存档）
底部：操作结果与键盘提示；关闭入口始终可见
```

初稿复核：单纯增加纸张纹理和金色边框仍会保留旧长表单的问题，因此先拆分玩家意图，再做材质与排版。任务页突出下一步和三项当前证据；信件单独阅读；联络采用列表/原文与明确已读动作；存档动作集中。导航数字仅用于真实的三步接班流程，不加入无意义编号、奖励分数或虚构仪表数据。

桌面采用导航与内页的容器布局；手机页签横排、内页独立滚动；短横屏收紧页头与边距。按钮触摸目标至少44px，正文以16px为基准，明确hover/focus/pressed/disabled/未读/已完成状态。动效只反馈打开/选择，尊重减少动态效果。原生dialog保留输入与暂停所有权；Tab焦点环绕、方向键切换页签、Esc先撤销新故事确认再返回场景。只声明实测的鼠标/键盘/触摸布局支持，不冒称手柄实机验收。

## 实际结果

已按上述两套技能重做[故事页面](../../public/index.html)与[展示控制器](../../src/examples/LighthouseStoryPanel.ts)。入口采用灯塔线描与明确主行动；游戏中为值守任务、交接信、岸站联络、保存与离开四页。任务展示真实三阶段和三项当前证据，信件保留全文与阅读动作，联络列表与原文分开、选择消息不自动已读。任务HUD改为海墨书签，时间菜单打开时让出操作区域。

分页、所选联络与每页滚动只属于展示状态。报告、回复、已读、保存/继续仍使用原场景命令；剧情、设备、存档格式和原两个存储键保持。新故事确认的背景入口设为inert，Tab限定在确认操作；Esc先撤销确认，页签支持方向键/Home/End，普通Tab保持在dialog内。减少动态效果时取消打开动画及按钮过渡。

### 截图复核及修正

- 第一稿短横屏的侧栏固有高度将内页撑过页脚：改为明确的`minmax(0,1fr)`行、侧栏独立溢出和短屏边距，新增内页不超过页脚的边界断言。
- 扩大的HUD原先遮挡时间菜单关闭按钮：菜单打开时隐藏HUD；原生操作验证关闭后重新可见。
- 手机联络列表横排时，收到的当前消息可能位于可视区外：选中或跨窄屏断点时仅滚动联络列表，让当前消息可见；原文页和游戏状态保持。
- 无存档时“开始新故事”为主按钮；内存继续优先于持久存档继续，避免多个同级主行动。损坏存档加载失败时停留存档页，保留清除入口及原失败保护。
- 截图等待打开动画完成后拍摄；桌面信件完整阅读需在内页滚动，页头/返回/页脚保持可达。最终画面及前后比较见[验收目录](assets/game-ui-journal-2026-10-22/README.md)。
