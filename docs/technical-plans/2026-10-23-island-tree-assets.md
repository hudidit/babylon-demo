# 岛屿树冠素材替换

状态：已替代（树形与图集）；历史工程验收保留。日期：2026-10-23。代码基线：`4d9487e`，交付：`f5172ba`。

用户指出稀疏枝层不自然，本方案的树形与512px图集由[树形与枝叶密度修正](2026-10-23-island-tree-form.md)替代。下文保留当时的检查和数量，不能据此把旧树形视为已获美术认可。

## 背景与目标

前三阶段已完成岛上A～E分区，但用户反馈闭合多面体树冠太假。此次是树冠表现方式调整：保留88棵树的根位、高度和林带疏密，用真实枝叶素材改善轮廓、空隙和颜色层次。丘体、灌木、草石、步道与交互不变；不以第四阶段为名加入风摆或全局光影。

遵循[资源与首屏优化原则](../resource-optimization-principles.md)和[原景观方案](2026-10-23-island-background-landscape.md)。历史阶段树冠几何前缀检查由本方案明确替代，位置、地形和非树植物的历史数据继续保护。

## 来源与取舍

- 采用 [Poly Haven Pine Tree 01](https://polyhaven.com/a/pine_tree_01) 的松针颜色和透明遮罩原图；摄影 Rob Tuytel，建模 Rico Cilliers。[官方许可](https://polyhaven.com/license)为 CC0，允许修改和随项目分发。获取日期2026-10-23。
- 官方API的1K Blend文件已达570,739,325 B，不整包引入。仅下载两张twig贴图，裁出针叶枝、组合成轻量分枝图集，并记录原件MD5/SHA256、处理脚本及交付摘要。原件可从官方固定URL重取，放在临时目录，运行仅包含派生图集及来源说明。
- 查阅过 Quaternius Ultimate Stylized Nature Pack（63模型，页面标CC0）和 ambientCG LeafSet017（CC0常春藤）；前者风格仍偏卡通，后者植物形态不适合本轮松林，均不接入。
- 采用共享PBR裁切贴图（alpha test，不做半透明混合）和固定的交错枝叶片，替换实心树冠和其旧小枝团。树干保留轻量几何；不逐叶建模，不增加动态光、阴影、逐帧回调或引擎依赖。新增一张小PNG图集、一个共享材质；尽量维持原19个景观批次。
- 裁切会增加纹理采样与像素覆盖成本，少量几何不能证明FPS无损。性能采样继续暂停，本轮只验证结构、字节、画面和交互。

## 实施顺序与验收

1. 保存基线生产目录和九机位×三尺寸画面；先做可回滚小样，检查轮廓是否比旧块体自然。
2. 可复现处理图集，维护来源与发布白名单；树冠按固定种子布置，近/远复杂度分级。根位、高度、非树几何保持；完整边界距可走区≥3m，地标视线无遮挡。
3. 共享材质沿用原昼夜/天气响应、裁切隔离和资源释放；丢失贴图时不得出现实体方块叶片或阻塞场景就绪，需要验证失败降级。
4. 不提高原四项字节预算：两GLB4.25MiB、运行素材16MiB、含必要异步首屏JS3MiB、完整dist41MiB；原海岸+景观≤166,000顶点、景观≤15,000三角形仍保留。基线运行15,867,377 B、首屏3,140,058 B、完整dist42,654,230 B，发布仅余337,386 B；控制图集及全部新增说明/JS在余量内。
5. 全量测试、类型、开发和生产构建；独立根/子路径全文件字节和SHA256、实际首屏JS、九机位三尺寸、昼夜/雾雨、移动/护栏、地图/设置/Inspector。保存实际截图、失败路径证据和边界，更新方案、索引、CHANGELOG、来源后提交推送。

## 实际结果

88棵树已采用真实松针图集，替换原实心树冠和第三阶段树上枝团。新增512×512 PNG一张（64,049 B）和共享PBR材质一个，景观仍19网格。累计10,129顶点、9,216三角形，相比原版增加208顶点、减少5,728三角形；原海岸加全部景观165,805≤166,000。完整包围盒距可走区至少8.050m，16条地标视线无遮挡；树木高度参数/根位、丘体和全部非树细节摘要与基线一致。

418项测试、类型、开发/生产构建及发布校验通过。Chrome 155的九机位×三尺寸27组姿态一致；昼夜/雾雨、地图/设置/Inspector及子路径启动通过。原生键盘与参考步进验证步行速度、护栏阻挡；贴图请求失败时仅隐藏9个树木批次，场景正常就绪，避免不透明方片。正常路径无运行/着色器错误或404，保留Inspector原CSS弃用提示与Webpack原三条体积建议。
