# 林缘树形、体积与近远过渡

状态：已完成（工程、Chrome画面/交互及覆盖复核）。日期：2026-10-23；基线：`3df3fc1`。用户本轮明确选择先改善静态树形、片状感和近远过渡。[覆盖方案](2026-10-23-island-forest-coverage.md)、[树形方案](2026-10-23-island-tree-form.md)及[资源原则](../resource-optimization-principles.md)为前置约束。原第四阶段风摆/动态树影仍待评估，性能采样保持暂停。

后续：[林下静态遮蔽](2026-10-23-island-forest-grounding.md)按植被位置修改地面已有顶点色，改善接地感；本页保留树形阶段的历史字节和画面记录。静态遮蔽不等同于风摆或动态树影。

## 背景与目标

上一轮已新增4,731株，树冠投影约覆盖全岛陆地74.6%。新林地统一采用同一整树图和8三角形替身，近处灌木像薄片、林缘树干/树冠缺少视差，远处轮廓重复；原树按整组屏幕占比0.002切换，缩放时变化可见。

本轮保持原植被根位、覆盖范围、路线、地形、天气和建筑；把有限几何优先分配给路边及主要观察方向，提升林缘立体感及全景变化，不直接增加所有树的几何。

## 方案与取舍

1. 同源离线烘焙两种不同枝冠轮廓，保持每个正/侧/顶视瓦片原分辨率，拼入1024×256图集。按固定树参数选择图案，叠加原旋转/明暗差。不得通过降低近景叶簇图清晰度腾预算；图集大小及实际alpha覆盖先小样验证。
2. 对靠近可走边界的树/灌木补真实树干、分叉枝与四个立体叶簇，复用与图集一致的81顶点/62三角形近树生成器及叶簇材质，再按相同视口/裁切比例变换，避免灌木变细干小树。最终距离：灌木12m内、树35m内，共93株；按原空间块合并，并保留其整树LOD。其余数千株继续8三角形。整个细节外廓必须留在原安全边界内。
3. 近树LOD切换推迟到更小的屏幕占比，优先让可见轮廓更稳定；限定静态单级切换，不新增逐帧每树逻辑、透明交叉淡化或阴影通道。参考[Babylon屏幕占比LOD](https://doc.babylonjs.com/features/featuresDeepDive/mesh/LOD)。按实际缩放和第一人称/鸟瞰画面调整参数，不将配置本身当成视觉验收。
4. 原88棵细节、根位/高度、丘体和非树景观保持；新增林地全部4,731株的根位/尺度/角度与基线逐项对照。新图集失败时退回可用近树细节，近树叶簇失败时保护其余远林与地形。

## 预算

原海岸及景观≤250,000顶点、景观≤55,000三角形，计入全部LOD备份；原几何仍≤166,000。基线228,476顶点/48,968三角形，只余6,032三角形，因此最多97株完整62三角形细节，不能无限推广。首轮112株远树几何与替身轮廓不匹配、灌木稀疏，改为93株同源精细树，对应+5,766三角形；缩小细节范围换取形态一致。

## 实际结果

### 已交付

- 保留原4,731株的根位、尺度和旋转，布局摘要`c495ecdf…b9be`与基线一致；原88棵细节、丘体、草石摘要也保持。没有扩大可走区或调整建筑/地形。
- 图集由一套改为两套整树正/侧/顶视轮廓，1024×256、44,626 B，比基线增加22,335 B；单个瓦片仍为128×256正/侧视、256×256冠顶。两种分叉方向与原旋转/明暗共同改变轮廓，远处仍为8三角形。冠顶透明边缘检查通过，无裁边；同源CC0派生纹理及ISC几何保持。
- 55棵树及38丛灌木（共93株）使用与图集相同的81顶点/62三角形模型，4个立体叶簇、3条主枝。模型按图集视口缩放、旋转；灌木裁切前的树干置于地面以下，避免小树感。增加6个细节批次及6个整树备份，复用原两种树材质，不增加材质/纹理数。
- 原9组树的LOD屏幕占比阈值从0.002收紧至0.0008，即缩得更小才换整树片；新增6组细节采用同一阈值。近/远测试机位分别选择0/1个低模组；属于按组离散切换，没有交叉淡化，也未彻底消除切换痕迹。
- 首轮112株远树几何虽然符合预算，但灌木过瘦、真实枝冠与贴图不匹配；改为93株同源近树几何后，树冠投影与远图基本一致。近树三角面与路线边界的连续间距≥3m、真实根位支撑和16条地标视线通过。
