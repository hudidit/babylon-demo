## 背景与现状

后续变更：[海边悬崖阶段A](2026-10-17-coastal-cliff-exterior.md)已替换运行中的森林几何/全景/树皮，原透明窗洞、共享世界、安全边界和室内功能沿用。本文件的森林画面、资源字节与验收数据为历史结果，历史素材及来源在仓库保留，已退出当前发布白名单；新海岸精细材质及动态海面仍待B/C。

六处窗户共用同一张78°透视森林照片，图片平面紧贴窗框，背后还有整块实心木板。照片的透视被固定在窗面，视角改变时没有窗框相对景物的遮挡变化，也没有近远景视差；各朝向重复同一构图。此前方案已明确该限制，用户现要求消除贴图感。

## 目标与范围

- 将窗框改为真实四边结构及透明玻璃；保持窗帘、窗台、窗洞尺寸与安全碰撞。
- 全屋共享固定世界坐标的室外森林。摄影全景只承担远景，近中景加入实际立体树干、分枝、树叶和起伏地面，移动时有不同距离的视差。
- 保持原室内光照、HDR、SSAO、镜面、家具与交互。室外材质使用局部光照，避免改变房间灯状态。
- 保持既有四项预算、pure导入和独立发布约束；不恢复此前暂停的FPS/加载耗时实验。

## 方案及取舍

1. 以现有CC0 Forest Slope原件生成完整等距柱状全景，替换旧透视裁片。上方使用220世界单位（44m）半径的内向环境面，远景树干区域延续至地面，下方的地面摄影投射到真实地形，UV连续。通过真实相机投影呈现，不随每个窗口缩放，不锁定屏幕UV。全屋不同朝向看到同一环境的不同方向。
2. 窗外使用确定性程序几何建立近中景，按区域/材质合批。外部几何不参与室内阴影、不阻塞拾取或室内通行；保持安全边界。避免每棵树独立高精模型和额外下载。
3. 透明玻璃采用很弱的冷色透射与高光，保留大部分景色，避免把室内HDR的其他房间反射到窗上。近中景的三维遮挡是主要深度来源，不用模糊图片掩盖平面。
4. 远景摄影仍是有限距离的近似，不能声称完整可漫游森林。程序林木需与实景色调、尺度相容；以近窗/侧视/阳台浏览器画面迭代，不仅验证几何。

实施取舍：曾检查独立重复地面贴图及直接压平整个下半球的候选，前者产生明显平直接缝，后者使摄影树根弯曲。最终保留照片树干的竖直远景带，仅将V≥0.67的地面区域向内投影；未保留候选地面图片。树皮由同源实拍树干裁出，消除程序竖纹与照片不协调的问题；低矮植被使用八棵有实际分枝的幼树，未保留不协调的程序蕨叶/夸张根部补丁。

技术依据：[Babylon环境映射与远景适用范围](https://doc.babylonjs.com/features/featuresDeepDive/materials/using/reflectionTexture/)、[Forest Slope来源与CC0](https://polyhaven.com/a/forest_slope)，并核对本地9.30.0的球体UV、透明材质与pure注册实现。

## 实施步骤

1. 保存当前生产目录清单、同视角近窗与侧视截图。
2. 打开窗框背板，接入共享远景和有深度的近中景；迭代视角与颜色。
3. 补充窗洞视觉通透/碰撞、场景共享、视差与释放回归测试，维护素材处理记录和白名单。
4. 运行测试、类型检查、开发及生产构建；独立托管检查横竖屏、相机移动、镜面/设置/Inspector及全部发布文件。
5. 保存测量与画面证据，更新文档/索引/变更日志，提交并推送。

## 验收方法

- 书房、主卧、次卧、客厅近窗及阳台：正视、贴近和侧看均能看到窗外，窗框后无木背板；各朝向构图符合共享环境。
- 同窗口左右平移观察，近树相对远景移动明显，景色不粘在玻璃上；近中远层存在几何深度和实际遮挡。
- 窗口、墙、阳台栏杆仍阻止玩家越界，原门/抽屉/灯/地图/信件功能不回退；窗外物体不会抢占交互射线。
- `npm test`、`npm run typecheck`、开发构建、`npm run build:production`通过；实际首屏含必需异步JS≤3 MiB，运行素材≤16 MiB，完整发布≤41 MiB；全部分包和来源说明独立托管摘要通过。
- 记录运行/着色器错误、404、告警、资源/顶点与前后字节。截图和确定性渲染只作功能画面证据，不作为FPS或加载速度收益。

## 实际结果

- 六窗已改为真实四边框架和透明玻璃，保留窗帘/窗台、洞口尺寸及防越界碰撞。新增[共享室外组件](../../src/examples/RoomExterior.ts)，16棵高树和8棵幼树使用有实际距离的树干/分枝/弯曲叶片；近景与摄影远景具有不同视差，各朝向看到同一森林的不同方向。全屋鸟瞰保持原展示背景，室内视角/第一人称启用室外。
- 全景保留4096×2048方向信息；树皮裁自同一CC0原件，采用[可复现脚本](../../tools/prepare-forest-panorama.py)从已固定摘要的原件处理，两张素材重复生成的SHA256一致。旧透视窗片移出运行目录，来源、白名单、发布测试和文档同步更新。
- [验收记录与同视角对比](assets/window-landscape-2026-10-17/README.md)保存93项测试、类型检查、开发/生产构建及最终独立托管结果。浏览器验证书房正视/斜视/左右平移、主卧/次卧/客厅/阳台和竖屏；横移1m时实际近树移动107.33px、远景19.78px。完整原交互、移动/窗户碰撞、地图/信件、设置/Inspector、真实镜面和释放/失败路径通过；489个发布文件GET/SHA256及`/home/`子路径通过。
- 素材14.97→15.70 MiB，静态初始JS2.40 MiB、含必需异步的实际首屏JS2.61 MiB，完整发布40.04→40.76 MiB；四项预算不变。网格539→548、顶点367,940→511,483，增加3个材质/1个纹理对象；灯/相机/阴影目标数量不变。正常流程无运行/着色器错误、404或浏览器告警，Webpack原有三类建议告警保留。没有测FPS、加载耗时或显存，不推断性能收益。
- 远景仍为摄影环境近似，地面投影不等同于完整扫描地形；仅近中景林木是真实三维几何。未增加室外漫游或风动画，既有阶段F/G和暂停的性能/听感事项保持原状态。
