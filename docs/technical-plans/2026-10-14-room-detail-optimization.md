## 背景与现状

前三项材质、光照和软体家具优化已完成；阅读区已有接触 AO、三处独立直接光投影及贴地灯底座。当前桌沿、椅架与窗框仍接近直角盒体；窗帘是长方体，植物为椭球叶片，窗外为程序插画。用户要求继续完成原方案第 4～6 项，并提供手机可辨识的局部放大截图。

## 目标与范围

- 第 4 项：为主要自建硬质家具加入小倒角、桌板分层、抽屉缝与椅架连接；保留已导入家具模型。
- 第 5 项：校验全室落地、桌面书本与杯碟接触，调整小范围遮蔽；保留三处直接光源，不以固定黑斑替代阴影。
- 第 6 项：使用有明确来源的实景窗外图，重做带叶脉、弯曲和分枝的植物以及有垂坠褶皱、绑带和挂环的窗帘。
- 保留现有布局、预设视角、第一人称与碰撞；交互性能目标更新为稳定 60 FPS，见 [帧率修复方案](2026-10-15-room-frame-rate.md)。下文 30 FPS 数据保留为当时限帧条件下的历史记录。

## 方案及取舍

1. 倒角使用尺寸不变的圆角盒体顶点构造，维持平面和沿边高光；按物体最薄尺寸限制半径，避免将木板变成软垫。圆桌增加薄边和下方结构。
2. 延续现有 SSAO2，重点校验物体实际接触和小件遮蔽；按近景结果决定参数，不叠加第二套全局 AO。
3. 植物用少量弯曲薄叶网格、共享叶脉材质与连续枝条代替椭球体；窗帘用静态布面网格实现从悬挂、收束到下摆的自然过渡，继续按材质合并静态网格。
4. 窗景从可追溯的 CC0 摄影全景取样并保存在本地；窗景仅作可见背景，不更换室内 HDR、不新增直接光源。平面背景不提供真实室外视差。
5. 截图直接从实际运行场景近距离取景，分别展示桌沿和书本、窗框和窗帘、植物叶片、家具落地；保存同机同视角基线与性能记录。

## 实施步骤

1. 保存原场景基线、读取几何与材质合并边界。
2. 实现硬质倒角与细节，校准桌面小件和家具落地。
3. 接入实景窗景，重做植物和窗帘。
4. 浏览器检查全景、预设视角、第一人称及局部近景，记录帧率和运行错误。
5. 执行测试、类型检查、构建；同步关联方案、索引与变更日志，提交推送并展示截图。

## 验收方法

- 近景可读出桌沿倒角、抽屉缝、书本封皮和纸页厚度；不产生明显破面或异常高光。
- 桌椅、植物盆及小件接触合理，AO 不产生大范围黑边，切换封闭房间后阴影刷新。
- 窗景为实景，窗帘有连续褶皱与垂坠，叶片有尖端、叶脉和弯曲且连接枝条。
- `npm test`、`npm run typecheck`、`npm run build` 通过；浏览器无运行错误，记录实际帧率和帧间隔，后续性能以帧率修复方案的目标验收。
- 至少交付一张整体截图和三张独立局部近景，避免把细节拼成手机难以看清的小图。

## 实施结果

### 第 4 项：硬质边缘与结构

- 新增 [RoomDetailGeometry.ts](../../src/examples/RoomDetailGeometry.ts)，为桌沿、桌裙、抽屉、椅架、窗框、门框及书本封皮生成平面保持不变的小倒角。倒角最大半径 0.065，并限制在最薄尺寸的 18% 内，外包尺寸不变。
- 写字桌增加分层桌沿、两只抽屉与黄铜拉环，桌裙改为四面框架；窗边桌增加抽屉内框和桌板层次，椅架补充横撑与连接销，茶几增加下沿。
- 书本分开表现封皮和纸页，纸页层纹根据局部高度校正 UV，避免不同侧面出现竖向页纹。书架上细小描金条保留简单几何，避免把近景倒角成本扩散至大量远景细条。

### 第 5 项：全室接触关系

- 继续使用上一轮的三处独立投影与 SSAO2；本轮没有叠加另一套 AO 或画固定黑斑。
- 消除写字桌、窗边桌、茶几、边桌和悬挂书架上书本的小间隙，连续三本书按封皮实际厚度堆叠。
- 杯碟、茶盘和台灯底座贴合对应支撑面；窗边小桌底座下移贴地并衔接桌柱，脚凳补充贴地底座。
- 台灯整体随底座下移 0.05，书桌光源同步由 y=0.85 调为 0.8，仍位于灯罩下方；光强、范围与其他光源职责保持上一轮校准结果。

### 第 6 项：窗景、植物与窗帘

- 窗景使用 Andreas Mischok 的 Poly Haven **Forest Slope** CC0 摄影全景，按透视视场重投影为 1600 × 1165 JPEG（约 1.1 MiB）。[来源清单](../../public/textures/study/forest-window/source.json) 保存官方 URL、源 MD5、交付 SHA256 和处理参数。场景只增加一个本地图片请求，不替换室内 HDR。
- 两盆植物各使用 32 片弯曲薄叶，共享叶脉纹理；叶片具有尖端、主脉和侧脉，连续锥形树干与枝条相连，无透明贴片排序问题。
- 窗帘使用双面连续布面，表现悬挂、六道褶皱、收束和散开的下摆，沿用扫描亚麻微表面；补充黄铜杆、挂环、绑绳和流苏。窗框增加压条与窗台层次。

- 14 项自动检查通过，覆盖原模型与交互回归，以及新倒角尺寸/法线方向、书本连续接触、桌面物件贴合、布面收束和薄叶轮廓。
- `npm run typecheck`、`npm run build` 通过。移除临时取景和采样代码后重新打开交付页面，确认第一人称移动、四个开放预设与封闭房间切换正常，运行错误为零；保存 [第一人称截图](assets/room-details-2026-10-14/after-first-person.jpg)，验证页面已关闭。
- 本轮代码、资源、截图、方案和变更日志随“feat: 完成书房硬质细节与窗边场景优化”提交一并保存，实施基线为 `718f742`。
